## 1. noindex 처리된 페이지 (메타 태그)

### 1.1 검색 페이지 (1개)

| 경로 | 파일 위치 | 설정 |
|------|----------|------|
| `/search` | `src/app/search/page.tsx` | `index: false, follow: true` |

**noindex 이유:** 검색 결과 페이지는 동적 콘텐츠로, 중복 콘텐츠 및 크롤 예산 낭비 방지

### 1.2 태그 페이지 (약 170+개)

| 경로 패턴 | 파일 위치 | 설정 |
|----------|----------|------|
| `/tag/[slug]` | `src/app/tag/[slug]/page.tsx` | `index: false, follow: true` |

**noindex 이유:**
- 크롤 예산 절약 (태그 페이지 크롤 요청 제거)
- 중복 콘텐츠 방지 (같은 게시글이 여러 태그에 중복 표시)
- 핵심 콘텐츠(게시글, 도구)에 크롤 리소스 집중

> 2026-02-03 대비 태그 수 감소: ~501개 → ~170+개 (91개 draft 처리로 활성 태그 감소)

## 5. SEO 영향 분석

### 현재 설정의 적절성

| 페이지 | 현재 설정 | 적절성 |
|--------|----------|--------|
