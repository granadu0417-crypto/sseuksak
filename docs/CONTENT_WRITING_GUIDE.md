| **도어웨이 페이지** | 검색 유입만 목적인 저품질 페이지 | "XX 가격", "XX 후기" 키워드 페이지 |

## 콘텐츠 유형별 작성 가이드

### 1. 정보성 콘텐츠 (가이드, 정책 안내)

#### 피해야 할 방식
```
제목: 2026년 최저임금 총정리

- 2026년 최저임금은 10,030원입니다.
- 월급으로 환산하면 2,096,270원입니다.
- 주휴수당 포함 시 ...
```
**문제점**: 어디서든 찾을 수 있는 정보 나열

#### 권장하는 방식
```
제목: 2026년 최저임금 인상, 내 월급은 얼마나 오를까? 실제 계산 사례

1. 기본 정보 (간략히)
   - 시급 10,030원, 월 2,096,270원

2. 실제 적용 사례 분석 (핵심 가치)
   - 편의점 아르바이트생 A씨의 경우
   - 중소기업 사무직 B씨의 경우
   - 계약직 C씨의 경우

3. 주의해야 할 점 (고유 인사이트)
   - 최저임금에 포함되지 않는 수당
   - 사업주가 자주 하는 실수
   - 임금 체불 시 대응 방법

4. 연봉 계산기로 내 상황 확인하기 (도구 연계)
```

### 2. 비교/분석 콘텐츠

#### 피해야 할 방식
```
제목: 2026년 적금 금리 비교

| 은행 | 금리 |
|------|------|
| A은행 | 4.5% |
| B은행 | 4.3% |
| C은행 | 4.1% |
```
**문제점**: 표 하나로 끝나는 단순 나열

#### 권장하는 방식
```
제목: 20대 사회초년생이 실제로 가입 가능한 적금 비교 (직접 확인)

1. 비교 기준 명시
   - 대상: 만 25세, 연소득 3000만원, 무주택자
   - 기간: 2026년 1월 기준
   - 방법: 각 은행 앱/고객센터 직접 확인

2. 실제 가입 가능 여부 분석
   | 적금명 | 표면 금리 | 실제 적용 금리 | 가입 가능 여부 | 이유 |
   |--------|----------|--------------|--------------|------|
   | A적금 | 5.0% | 3.5% | △ | 우대조건 2개만 충족 |
   | B적금 | 4.5% | 4.5% | ○ | 조건 없음 |
   | C적금 | 6.0% | - | X | 첫 거래 고객만 |

3. 숨겨진 조건 분석 (고유 가치)
   - "첫 거래 고객" 정의가 은행마다 다름
   - 우대금리 조건 중 실현 어려운 것들
   - 중도 해지 시 금리 차이

4. 결론 및 추천
   - 상황별 추천 적금
   - 적금 금리 비교 도구 연계
```

### 3. 경험 기반 콘텐츠

#### 피해야 할 방식
```
제목: 연말정산 하는 방법

1. 홈택스 접속
2. 간소화 서비스 클릭
3. 자료 조회
4. 회사에 제출
```
**문제점**: 공식 가이드와 동일한 내용

#### 권장하는 방식
```
제목: 직장인 3년차, 연말정산으로 50만원 더 환급받은 방법

1. 배경 (신뢰성 확보)
   - 연봉 4500만원, 무주택 1인 가구
   - 작년 환급액: 23만원 → 올해: 73만원

2. 놓치기 쉬운 공제 항목 (실제 경험)
   - 월세 세액공제: 처음엔 몰라서 못 받음
   - 안경 구매비: 영수증 따로 챙겨야 함
   - 교육비: 온라인 강의도 해당

3. 실수했던 점과 해결 방법
   - 부양가족 공제 중복 문제
   - 신용카드 vs 체크카드 비율 최적화

4. 환급액 극대화 체크리스트
   - [ ] 월세 계약서 준비
   - [ ] 안경 구매 영수증 챙기기
   - [ ] ...

5. 연말정산 계산기로 예상 환급액 확인 (도구 연계)
```

## 콘텐츠 작성 체크리스트

### 작성 전 확인

- [ ] 이 주제로 검색했을 때 상위 5개 글에 없는 정보가 있는가?
- [ ] 실제 경험, 데이터, 분석이 포함될 수 있는가?
- [ ] 사이트의 도구/테스트와 연계할 수 있는가?

### 작성 중 확인

- [ ] 단순 정보 나열이 아닌 분석/인사이트가 있는가?
- [ ] 독자가 "이 글 덕분에 해결됐다"고 할 수 있는가?
- [ ] 구체적인 숫자, 사례, 시나리오가 포함되어 있는가?
- [ ] 출처와 참고문헌이 명시되어 있는가?

### 작성 후 확인

- [ ] 글 분량이 최소 1500자 이상인가?
- [ ] 이미지/표/리스트로 가독성이 좋은가?
- [ ] 관련 도구나 다른 글로의 내부 링크가 있는가?
- [ ] 메타 설명(description)이 적절한가?

## 콘텐츠 품질 평가 기준

### 5점 척도 자가 평가

| 항목 | 1점 | 3점 | 5점 |
|------|-----|-----|-----|
| **고유성** | 어디서든 찾을 수 있음 | 일부 고유 정보 있음 | 이 글에서만 볼 수 있음 |
| **깊이** | 표면적 정보만 | 기본 분석 포함 | 심층 분석과 인사이트 |
| **실용성** | 읽고 끝 | 일부 도움됨 | 바로 적용 가능 |
| **신뢰성** | 출처 없음 | 일부 출처 있음 | 공식 출처 + 경험 |
| **연계성** | 단독 글 | 관련 글 링크 | 도구/테스트 연계 |

**목표**: 각 항목 평균 4점 이상

## 카테고리별 콘텐츠 방향

### finance (금융/재테크)
- 실제 금융 상품 비교 분석 (직접 확인한 내용)
- 절세/환급 경험담
- 투자 시뮬레이션 및 분석
- **연계 도구**: 연봉 계산기, FIRE 계산기, 적금 비교

### lifestyle (라이프스타일)
- 실생활 팁과 경험담
- 구독/지출 관리 후기
- 건강/수면 실험 결과
- **연계 도구**: 수면 계산기, 알코올 분해 계산기, 구독 정리

### tech (기술/IT)
- 신제품 실사용 비교 (스펙 나열 X)
- 서비스/앱 실제 사용 후기
- 기술 트렌드 분석과 전망
- **연계 테스트**: 관련 심리 테스트

### health (건강)
- 건강검진/예방접종 실제 경험
- 의료비 절약 팁 (실제 사례)
- 건강 관련 제도 활용법
- **연계 도구**: 건강 관련 계산기

### insurance (보험)
- 보험 상품 실제 비교 (약관 분석)
- 보험금 청구 경험담
- 보험 선택 시 주의점
- **연계**: 보험료 계산, 보장 분석

### education (교육)
- 자격증/시험 준비 경험담
- 교육 정책 실제 적용 사례
- 학습 방법 실험 결과
- **연계 테스트**: 학습 스타일 테스트

## 출처 및 참고문헌 작성 가이드

### 필수 포함 출처

| 콘텐츠 유형 | 필수 출처 |
|------------|----------|
| 정책/제도 | 관련 정부 기관 (국세청, 고용노동부 등) |
| 금융 상품 | 금융감독원, 해당 금융기관 공식 사이트 |
| 건강/의료 | 국민건강보험공단, 질병관리청 |
| 통계/데이터 | 통계청, 한국은행 |

### 출처 작성 형식

```markdown
---

## 출처 및 참고문헌

- [기관명] 문서/페이지명 (연도)
  - URL 또는 "해당 기관 공식 발표 자료"
- [기관명] 문서/페이지명 (연도)
  - URL 또는 설명

*본 글의 정보는 작성일(YYYY-MM-DD) 기준이며,
정책/제도 변경 시 내용이 달라질 수 있습니다.*
```
