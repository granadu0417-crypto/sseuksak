# 콘텐츠 작성 가이드

sseuksak.com 블로그의 AdSense 승인 및 SEO 최적화를 위한 콘텐츠 작성 가이드입니다.

---

## Google 정책 핵심 요약

### AdSense 승인을 위한 필수 조건

| 요건 | 설명 |
|------|------|
| **실질적 부가가치** | 다른 사이트에서 찾기 어려운 고유 정보 제공 |
| **고유 콘텐츠** | 스크래핑/복사가 아닌 직접 작성한 콘텐츠 |
| **사용자 가치** | 독자가 실제로 문제를 해결할 수 있는 내용 |
| **전문성/경험** | 개인 경험, 전문 지식 기반의 인사이트 |

### 피해야 할 콘텐츠 (Google 스팸 정책)

| 유형 | 설명 | 예시 |
|------|------|------|
| **확장된 콘텐츠 악용** | AI로 대량 생성한 가치 없는 콘텐츠 | 키워드만 바꾼 유사 글 대량 생산 |
| **빈약한 제휴 페이지** | 제품 설명만 복사한 어필리에이트 | 쿠팡 파트너스 링크만 있는 글 |
| **스크래핑** | 다른 사이트 내용 복사/재구성 | 뉴스 기사 요약만 한 글 |
| **도어웨이 페이지** | 검색 유입만 목적인 저품질 페이지 | "XX 가격", "XX 후기" 키워드 페이지 |

## AI 콘텐츠 패턴 방지 규칙 (AdSense 필수)

> **배경**: AdSense 심사에서 "가치가 별로 없는 콘텐츠" 판정을 받았습니다.
> Google은 "확장된 콘텐츠 악용(Scaled Content Abuse)"을 스팸으로 분류하며,
> AI 도구로 대량 생성한 획일적 콘텐츠를 명시적으로 경고합니다.
> 아래 규칙을 반드시 지켜주세요.

### 절대 금지: 7가지 AI 핑거프린트

글을 작성할 때 아래 패턴이 **하나라도** 발견되면 수정해야 합니다.

| # | AI 패턴 | 구체적 예시 | 대안 |
|---|---------|-----------|------|
| 1 | **수사 질문으로 시작** | `"XX 고민이시죠?"`, `"XX 알고 계셨나요?"` | 팩트/숫자/뉴스로 시작 |
| 2 | **"오늘은...정리해드릴게요"** | `오늘은 2026년 적금 금리를 정리해드릴게요` | 사용 금지. 바로 본론 진입 |
| 3 | **획일적 H2-H3-H4 계층** | 모든 글이 동일한 헤딩 깊이/순서 | 카테고리별 다른 구조 사용 |
| 4 | **항목/내용 2열 테이블 남용** | 모든 정보를 `항목 | 내용` 테이블로 | 산문, 번호 리스트, 인용 등 혼용 |
| 5 | **3단계 마무리 공식** | 요약 + 응원 문구 + 면책 조항 | 글마다 다른 마무리 방식 |
| 6 | **반복 전환 표현** | `그럼 하나씩 살펴볼까요?`, `핵심 포인트:` | 자연스러운 연결 문장 사용 |
| 7 | **9단계 글 구조 반복** | 도입→개요→상세→비교→주의→FAQ→요약→CTA→출처 | 글마다 구조를 바꿔서 작성 |

### 도입부 다양화 규칙

같은 방식으로 시작하는 글이 3개 이상 연속되면 안 됩니다. 아래에서 돌려가며 사용하세요.

| 유형 | 예시 |
|------|------|
| **숫자/통계 시작** | `한국은행 기준금리가 2.75%로 내려간 지 두 달째다.` |
| **뉴스/시사 시작** | `지난주 금융위원회가 발표한 저축은행 금리 현황을 보면...` |
| **결론 먼저** | `결론부터 말하면, 2026년 1월 기준 가장 금리가 높은 적금은 XX은행 XX적금이다.` |
| **상황 묘사** | `월급날, 통장 잔고를 확인하고 한숨을 쉰 적 있다면.` |
| **비교/대조** | `시중은행 3.5% vs 저축은행 5.0%. 이 차이가 1년 뒤 얼마나 벌어질까?` |
| **오해 바로잡기** | `"저축은행은 위험하다"는 말, 반은 맞고 반은 틀리다.` |
| **정의/개념 시작** | `최저임금이란 국가가 법으로 정한 "이보다 적게 주면 불법"인 시급의 마지노선이다.` |
| **경험담/일화** | `편의점에서 3년째 일하는 후배가 물었다. "형, 내년에 시급 오른다는데 나도 해당돼?"` |
| **명언/격언 인용** | `"임금을 제때 주지 않는 것은 노동을 훔치는 것이다." ILO 헌장의 정신이다.` |
| **가정법/시나리오** | `주 5일 하루 8시간 일하는 직장인이 두 명 있다. 같은 시간인데 연봉이 400만원 차이 난다.` |
| **목적/이유 선언** | `최저임금 뉴스는 매년 나오지만, 정작 '내 급여가 맞는지' 확인하는 사람은 드물다.` |
| **반전/의외의 사실** | `2026년 최저임금이 1만원을 넘겼다고 축하할 일만은 아니다. 실질 구매력은 2018년 수준에 못 미친다.` |

### 구조 다양화 규칙

아래 8가지 구조 중 하나를 선택하되, **같은 카테고리 내에서 연속 2개 이상 같은 구조 사용 금지**.

**구조 A: 역피라미드형** (뉴스/시사 콘텐츠)
```
결론/핵심 → 세부 설명 → 배경/맥락 → 관련 정보
```

**구조 B: 문제-해결형** (가이드/How-to 콘텐츠)
```
상황 설명 → 왜 문제인지 → 해결 방법 단계별 → 주의사항
```

**구조 C: 비교-분석형** (비교/리뷰 콘텐츠)
```
비교 기준 제시 → 각 항목 심층 분석 → 상황별 추천 → 실제 선택 팁
```

**구조 D: 단계별 가이드형** (절차/신청 방법 콘텐츠)
```
배경/왜 필요한지 → 준비물/전제조건 → 1단계 → 2단계 → ... → 완료 후 확인 → 자주 하는 실수
```

**구조 E: PREP형** (의견/분석 콘텐츠)
```
핵심 주장 → 그렇게 말하는 이유 2-3가지 → 실제 사례/데이터 → 주장 재확인 + 행동 제안
```

**구조 F: FAQ/Q&A형** (자주 묻는 질문 콘텐츠)
```
주제 소개 2-3줄 → Q1: 가장 많이 묻는 질문 → A1 → Q2 → A2 → ... → 추가 팁
```

**구조 G: 타임라인/연대기형** (변천사/일정 콘텐츠)
```
현재 상황 스냅샷 → 과거 배경 → 시간순 전개 → 현재 → 앞으로의 전망
```

**구조 H: Before-After형** (경험/변화 사례 콘텐츠)
```
Before 상황 → 문제의 심각성 → 전환점/해결 → After 결과 → 핵심 포인트
```

### E-E-A-T 신호 삽입 (필수)

Google은 "전문 지식이나 개선 제안, 리뷰, 개인적인 의견 등 고유한 콘텐츠를 추가"할 것을 요구합니다.

**모든 글에 아래 요소 중 최소 2개를 포함하세요:**

| E-E-A-T 요소 | 구현 방법 | 예시 |
|-------------|----------|------|
| **Experience (경험)** | 직접 해본 결과, 후기, 실패담 | `실제로 A은행 앱에서 가입해보니 우대조건 충족이 까다로웠다` |
| **Expertise (전문성)** | 데이터 분석, 계산 결과, 비교표 | `금감원 공시 데이터를 직접 비교한 결과...` |
| **Authoritativeness (권위)** | 공식 출처 인용, 전문가 의견 | `국세청 공식 안내에 따르면...` |
| **Trustworthiness (신뢰)** | 한계 인정, 업데이트 날짜, 면책 | `이 정보는 2026년 1월 기준이며, 금리는 수시로 변동됩니다` |

### 고유 가치 체크: "쿠키 커터 테스트"

글 작성 후 아래 질문에 **모두 "아니오"**라고 답할 수 있어야 합니다:

- [ ] 이 글의 제목만 바꾸면 다른 주제의 글과 구조가 동일한가?
- [ ] 개인적 관점이나 분석 없이 정보만 나열했는가?
- [ ] 다른 사이트의 같은 주제 글과 내용이 거의 같은가?
- [ ] 카테고리가 다른 글들과 헤딩 구조가 동일한가?

## 콘텐츠 유형별 작성 가이드

### 1. 정보성 콘텐츠 (가이드, 정책 안내)

#### 피해야 할 방식
```
제목: 2026년 최저임금 총정리

- 2026년 최저임금은 10,320원입니다.
- 월급으로 환산하면 2,156,880원입니다.
- 주휴수당 포함 시 ...
```
**문제점**: 어디서든 찾을 수 있는 정보 나열

#### 권장하는 방식
```
제목: 2026년 최저임금 인상, 내 월급은 얼마나 오를까? 실제 계산 사례

1. 기본 정보 (간략히)
   - 시급 10,320원, 월 2,156,880원

2. 실제 적용 사례 분석 (핵심 가치)
   - 편의점 아르바이트생 A씨의 경우
   - 중소기업 사무직 B씨의 경우
   - 계약직 C씨의 경우

3. 주의해야 할 점 (고유 인사이트)
   - 최저임금에 포함되지 않는 수당
   - 사업주가 자주 하는 실수
   - 임금 체불 시 대응 방법

4. 연봉 계산기로 내 상황 확인하기 (도구 연계)
```

### 2. 비교/분석 콘텐츠

#### 피해야 할 방식
```
제목: 2026년 적금 금리 비교

| 은행 | 금리 |
|------|------|
| A은행 | 4.5% |
| B은행 | 4.3% |
| C은행 | 4.1% |
```
**문제점**: 표 하나로 끝나는 단순 나열

#### 권장하는 방식
```
제목: 20대 사회초년생이 실제로 가입 가능한 적금 비교 (직접 확인)

1. 비교 기준 명시
   - 대상: 만 25세, 연소득 3000만원, 무주택자
   - 기간: 2026년 1월 기준
   - 방법: 각 은행 앱/고객센터 직접 확인

2. 실제 가입 가능 여부 분석
   | 적금명 | 표면 금리 | 실제 적용 금리 | 가입 가능 여부 | 이유 |
   |--------|----------|--------------|--------------|------|
   | A적금 | 5.0% | 3.5% | △ | 우대조건 2개만 충족 |
   | B적금 | 4.5% | 4.5% | ○ | 조건 없음 |
   | C적금 | 6.0% | - | X | 첫 거래 고객만 |

3. 숨겨진 조건 분석 (고유 가치)
   - "첫 거래 고객" 정의가 은행마다 다름
   - 우대금리 조건 중 실현 어려운 것들
   - 중도 해지 시 금리 차이

4. 결론 및 추천
   - 상황별 추천 적금
   - 적금 금리 비교 도구 연계
```

### 3. 경험 기반 콘텐츠

#### 피해야 할 방식
```
제목: 연말정산 하는 방법

1. 홈택스 접속
2. 간소화 서비스 클릭
3. 자료 조회
4. 회사에 제출
```
**문제점**: 공식 가이드와 동일한 내용

#### 권장하는 방식
```
제목: 직장인 3년차, 연말정산으로 50만원 더 환급받은 방법

1. 배경 (신뢰성 확보)
   - 연봉 4500만원, 무주택 1인 가구
   - 작년 환급액: 23만원 → 올해: 73만원

2. 놓치기 쉬운 공제 항목 (실제 경험)
   - 월세 세액공제: 처음엔 몰라서 못 받음
   - 안경 구매비: 영수증 따로 챙겨야 함
   - 교육비: 온라인 강의도 해당

3. 실수했던 점과 해결 방법
   - 부양가족 공제 중복 문제
   - 신용카드 vs 체크카드 비율 최적화

4. 환급액 극대화 체크리스트
   - [ ] 월세 계약서 준비
   - [ ] 안경 구매 영수증 챙기기
   - [ ] ...

5. 연말정산 계산기로 예상 환급액 확인 (도구 연계)
```

#### 작성 구조
```
1. 문제 제기 (공감)
   - 많은 사람들이 궁금해하는 점

2. 기본 지식 (간략히)
   - 필요한 배경 정보

3. 실제 분석/사례 (핵심 가치)
   - 구체적인 숫자와 시나리오
   - 다양한 상황별 비교

4. 도구 활용 안내 (CTA)
   - "직접 계산해보세요" + 도구 링크

5. 추가 팁/주의사항
   - 도구만으로는 알 수 없는 정보
```

## 콘텐츠 작성 체크리스트

### 작성 전 확인

- [ ] 이 주제로 검색했을 때 상위 5개 글에 없는 정보가 있는가?
- [ ] 실제 경험, 데이터, 분석이 포함될 수 있는가?
- [ ] 사이트의 도구/테스트와 연계할 수 있는가?
- [ ] 최근 3개 글과 **다른 도입부 유형**을 선택했는가?
- [ ] 같은 카테고리 내 최근 글과 **다른 구조(A/B/C)**를 선택했는가?

### 작성 중 확인

- [ ] 단순 정보 나열이 아닌 분석/인사이트가 있는가?
- [ ] 독자가 "이 글 덕분에 해결됐다"고 할 수 있는가?
- [ ] 구체적인 숫자, 사례, 시나리오가 포함되어 있는가?
- [ ] 출처와 참고문헌이 명시되어 있는가?
- [ ] **E-E-A-T 요소가 2개 이상** 포함되어 있는가?
- [ ] `"오늘은...정리해드릴게요"` 같은 **AI 전형 표현이 없는가**?
- [ ] `항목/내용` 2열 테이블만으로 정보를 전달하고 있지 않은가?

### 작성 후 확인

- [ ] 글 분량이 최소 1500자 이상인가?
- [ ] 이미지/표/리스트로 가독성이 좋은가?
- [ ] 관련 도구나 다른 글로의 내부 링크가 있는가?
- [ ] 메타 설명(description)이 적절한가?
- [ ] **쿠키 커터 테스트** 4개 항목을 통과하는가?

## 콘텐츠 품질 평가 기준

### 5점 척도 자가 평가

| 항목 | 1점 | 3점 | 5점 |
|------|-----|-----|-----|
| **고유성** | 어디서든 찾을 수 있음 | 일부 고유 정보 있음 | 이 글에서만 볼 수 있음 |
| **깊이** | 표면적 정보만 | 기본 분석 포함 | 심층 분석과 인사이트 |
| **실용성** | 읽고 끝 | 일부 도움됨 | 바로 적용 가능 |
| **신뢰성** | 출처 없음 | 일부 출처 있음 | 공식 출처 + 경험 |
| **연계성** | 단독 글 | 관련 글 링크 | 도구/테스트 연계 |

**목표**: 각 항목 평균 4점 이상

## 카테고리별 콘텐츠 방향

### finance (금융/재테크)
- 실제 금융 상품 비교 분석 (직접 확인한 내용)
- 절세/환급 경험담
- 투자 시뮬레이션 및 분석
- **연계 도구**: 연봉 계산기, FIRE 계산기, 적금 비교

### lifestyle (라이프스타일)
- 실생활 팁과 경험담
- 구독/지출 관리 후기
- 건강/수면 실험 결과
- **연계 도구**: 수면 계산기, 알코올 분해 계산기, 구독 정리

### tech (기술/IT)
- 신제품 실사용 비교 (스펙 나열 X)
- 서비스/앱 실제 사용 후기
- 기술 트렌드 분석과 전망
- **연계 테스트**: 관련 심리 테스트

### health (건강)
- 건강검진/예방접종 실제 경험
- 의료비 절약 팁 (실제 사례)
- 건강 관련 제도 활용법
- **연계 도구**: 건강 관련 계산기

### insurance (보험)
- 보험 상품 실제 비교 (약관 분석)
- 보험금 청구 경험담
- 보험 선택 시 주의점
- **연계**: 보험료 계산, 보장 분석

### education (교육)
- 자격증/시험 준비 경험담
- 교육 정책 실제 적용 사례
- 학습 방법 실험 결과
- **연계 테스트**: 학습 스타일 테스트
