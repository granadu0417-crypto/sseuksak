sseuksak.com에 퀴즈/테스트 콘텐츠 적용을 위한 경쟁사 분석 문서입니다.

| 사이트 | URL | 특징 |
|--------|-----|------|
| **테스트모아** | testmoa.com | 심리테스트, 능력고사, MBTI 변형 |

## 1. 테스트모아 (testmoa.com) 분석

### 사이트 구조

```
홈페이지: testmoa.com
├── 카테고리: 성격, 능력, 퀴즈, 전문
├── 테스트 랜딩: testmoa.com/[test-name]/
├── 테스트 실행: service.testmoa.com/[test-name]/
└── 결과 페이지: service.testmoa.com/[test-name]/result/[grade].html
```

### 테스트 플로우

1. **랜딩 페이지**: 테스트 소개, 시작 버튼
2. **질문 페이지**: 3개 선택지 버튼 UI
3. **점수 계산**: JavaScript 변수 (fdScore, lvScore)
4. **결과 페이지**: 등급 표시 (AA+, A, B 등)

### UX 특징

| 요소 | 구현 방식 |
|------|----------|
| 질문 UI | 3개 버튼 (세로 배열) |
| 진행률 | 상단 프로그레스 바 |
| 결과 | 등급 + 설명 + 공유 이미지 |
| 공유 | 카카오톡, 트위터 버튼 |

### 수익화 모델

- **쿠팡 파트너스**: 결과 페이지 팝업으로 광고 표시
- **광고 제거 유도**: "광고 제거하기" 버튼 → 쿠팡 링크 클릭

### 인기 테스트 유형

- MBTI 변형 (TF 능력고사, 결혼 능력고사)
- 심리테스트 (에겐 테토, 성격 테스트)
- 능력 평가 (여자어/남자어 능력 평가)
- 반응속도 테스트

## 2. 푸망 (poomang.com) 분석

### 사이트 구조

```
홈페이지: poomang.com
├── 최신 심테
├── 이번주 인기 TOP 12
├── 푸망 시리즈 (자체 제작)
├── 테마별 모음 (동물, 계절 등)
├── 테스트 상세: poomang.com/detail/[id]
└── 사용자 계정, 댓글 시스템
```

### 테스트 상세 페이지 구성

| 섹션 | 내용 |
|------|------|
| 메타정보 | 제목, 제작자, 조회수, 소요시간 |
| 설명 | 테스트 소개 텍스트 |
| 태그 | #사랑, #돈, #패션 등 |
| 액션 | 테스트 시작 버튼 |
| 반응 | 저장하기, 재밌어요, 정확해요, 공유하기 |
| 댓글 | 사용자 결과 공유, 좋아요/싫어요 |
| 추천 | 비슷한 테스트 |

### UX 특징

| 요소 | 구현 방식 |
|------|----------|
| 썸네일 | 귀여운 일러스트 스타일 |
| 조회수 | 플레이 횟수 표시 (예: 42.9만) |
| 소요시간 | "약 2분" 형태로 표시 |
| 사용자 참여 | 댓글, 반응 버튼 |

### 인기 테스트 (조회수 기준)

| 테스트 | 조회수 |
|--------|--------|
| 에겐녀 테스트 | 200.6만 |
| 운명의 동물 테스트 | 144.6만 |
| 조선시대 관상 테스트 | 42.9만 |
| 나만의 위키 테스트 | 42.4만 |
| 멘헤라 테스트 | 24.7만 |

### 콘텐츠 카테고리

- **시즌 테마**: 겨울, 신년, 크리스마스
- **동물 테마**: 운명의 동물, 햄스터, 댕댕이
- **트렌드**: 2026년 운세, ChatGPT 중독
- **연애/성격**: MBTI 변형, 연애 스타일

### 수익화 모델

- **배너 광고**: 상단 고정 광고 (AmazingTalker 등)
- **앱 다운로드 유도**: 푸망 앱
- **제휴 문의**: B2B 협업

## 3. 공통 패턴 및 성공 요인

### 콘텐츠 특성

| 특성 | 설명 |
|------|------|
| **짧은 소요시간** | 2-5분 내 완료 |

| **개인화** | "나만의", "내 결과" 등 개인 맞춤형 |

```
┌─────────────────────────────────┐
│         테스트 썸네일            │
│    (귀여운 일러스트 스타일)       │
├─────────────────────────────────┤
│  테스트 제목                     │
│  ▷ 조회수  ⏱ 소요시간           │
├─────────────────────────────────┤

├─────────────────────────────────┤

│      [ 테스트 시작하기 ]         │
```

2. **결과 이미지**: SNS 공유용 최적화된 이미지
3. **호기심 유발**: "나는 몇 %?", "내 유형은?" 등
4. **비교 욕구**: 친구와 결과 비교

## 4. sseuksak.com 적용 권장사항

### 4.1 적합한 테스트 유형

sseuksak.com의 주제(금융, 생활정보)에 맞는 테스트:

| 카테고리 | 테스트 아이디어 | 예상 인기도 |
|----------|----------------|------------|
| **금융** | 나의 소비 유형 테스트 | ⭐⭐⭐⭐⭐ |
| **금융** | 2026년 재테크 성향 테스트 | ⭐⭐⭐⭐ |
| **세금** | 연말정산 환급 예측 퀴즈 | ⭐⭐⭐⭐ |
| **생활** | 나의 절약 레벨 테스트 | ⭐⭐⭐⭐ |
| **투자** | 나는 어떤 투자자 유형? | ⭐⭐⭐⭐⭐ |
| **보험** | 나에게 필요한 보험 찾기 | ⭐⭐⭐ |

### 4.2 기술 구현 방안

#### Option A: 정적 페이지 방식 (권장)

```
/tests/[test-slug]/           - 테스트 랜딩
/tests/[test-slug]/play       - 테스트 진행 (클라이언트 사이드)
/tests/[test-slug]/result/[type] - 결과 페이지 (SSG)
```

**장점**:
- SEO 최적화 (각 결과 페이지 색인 가능)
- 서버 부하 없음
- Cloudflare Workers와 호환

#### Option B: 클라이언트 전용 방식

```
/tests/[test-slug]/           - 단일 페이지 앱
```

**장점**:
- 구현 단순
- 상태 관리 용이

### 4.3 필수 구현 요소

1. **테스트 컴포넌트**
   - 질문 카드 UI
   - 선택지 버튼 (2-4개)
   - 진행률 표시
   - 애니메이션 전환

2. **결과 페이지**
   - 결과 유형/점수 표시
   - 상세 설명
   - 공유 버튼 (카카오, 트위터)
   - 관련 글 추천

3. **메타 데이터**
   - OG 이미지 (결과별)
   - JSON-LD 구조화 데이터

### 4.4 수익화 연계

| 테스트 유형 | 연계 콘텐츠 |
|------------|------------|
| 소비 유형 | → 신용카드 비교 글 |
| 투자 성향 | → ETF 가이드 글 |
| 절약 레벨 | → 연말정산 환급 글 |
| 보험 찾기 | → 보험 비교 글 |

### 4.5 콘텐츠 기획 원칙

1. **정보 + 재미**: 단순 재미보다 유용한 정보 제공
2. **신뢰성**: 근거 있는 분류 기준 (재무 데이터 기반)
3. **시즌 연계**: 연말정산, 신년 계획 등 시기 활용
4. **실용성**: 테스트 후 액션 가이드 제공
