## 색인 요청 방법

### Google Search Console - 대량 색인 요청 (권장)

**"수정 결과 확인" 기능 사용** - 가장 효율적인 방법

1. [Google Search Console](https://search.google.com/search-console) 접속
2. 좌측 메뉴: **색인생성** > **페이지** 클릭
3. 하단으로 스크롤하여 미색인 사유 클릭 (예: "발견됨 - 현재 색인이 생성되지 않음")
4. **"수정 결과 확인"** 버튼 클릭
5. 유효성 검사가 시작되며, Google이 해당 URL들을 재크롤링

### Google Search Console - 개별 URL 색인 요청

1. 상단 검색창에 URL 입력
2. URL 검사 결과 확인
3. "색인 생성 요청" 버튼 클릭
4. **주의**: URL당 1-2분 소요, 일일 할당량 제한 있음

### 네이버 서치어드바이저

1. [네이버 서치어드바이저](https://searchadvisor.naver.com) 접속
2. 좌측 메뉴: **요청** > **웹 페이지 수집** 또는 **사이트맵 제출**
3. 사이트맵이 이미 제출되어 있으면 추가 작업 불필요

### IndexNow (Naver/Bing 동시)

```bash
# scripts/indexnow.js 실행 (draft 제외, 공개 URL만)
node scripts/indexnow.js
```

배포 시 `cf:quick` / `cf:deploy`에 IndexNow가 자동 포함됨.

## 색인 상태별 대응

| 상태 | 의미 | 대응 |
|------|------|------|
| 발견됨 - 현재 색인이 생성되지 않음 | sitemap에서 URL 발견, 미크롤링 | "수정 결과 확인"으로 재검토 요청 |
| 크롤링됨 - 현재 색인이 생성되지 않음 | 크롤링 했으나 품질 문제 | 콘텐츠 품질 개선 후 재요청 |
| 중복 - 제출된 URL이 표준으로 선택되지 않음 | 다른 URL이 canonical로 선택 | canonical 태그 확인 및 수정 |
