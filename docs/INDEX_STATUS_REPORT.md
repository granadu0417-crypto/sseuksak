### 문제 분석

#### 1) "발견됨 - 현재 색인이 생성되지 않음" (57개)

**의미**: Google이 sitemap이나 내부 링크를 통해 URL을 발견했지만, 아직 크롤링하지 않은 상태

**원인**:
- **신규 사이트**: sseuksak.com은 비교적 새로운 사이트로 크롤링 우선순위가 낮음
- **크롤 예산 제한**: Google은 새 사이트에 제한된 크롤 예산 할당
- **콘텐츠 급증**: 단기간에 85개 게시글이 추가되어 크롤러가 따라가지 못함
- **사이트 권위도**: 아직 도메인 권위가 충분히 쌓이지 않음

**해결 방안**:
1. 시간이 지나면 자연스럽게 크롤링됨 (2-4주 소요 가능)
2. 고품질 백링크 확보로 사이트 권위 향상
3. 소셜 미디어 공유로 트래픽 유입
4. Google Search Console에서 수동 색인 요청 (하루 제한 있음)

#### 2) "찾을 수 없음 (404)" (2개) - **해결됨**

**404 오류 URL 상세** (2026-02-03 확인):

| URL | Google 크롤링일 | 현재 상태 |
|-----|----------------|----------|
| `https://sseuksak.com/tag/전세자금대출` | 2026.01.12 | **200 (정상)** |
| `https://sseuksak.com/tag/주담대금리` | 2026.01.11 | **200 (정상)** |

**분석 결과**:
- 두 URL 모두 태그 페이지이며, 현재는 정상 작동 (HTTP 200)
- Google이 1월 11-12일 크롤링 당시 일시적으로 404 발생 추정 (배포 중 또는 태그 시스템 구축 전)
- 해당 태그들은 게시글에 존재함:
  - `전세자금대출` → `jeonse-loan-comparison-2026.md`
  - `주담대금리` → `mortgage-rate-comparison-2026.md`

**결론**:
- **조치 불필요** - 이미 해결된 상태
- 태그 페이지는 noindex 처리되어 있어 색인 대상 아님
- Google 재크롤링 시 자동으로 404 목록에서 제거 예정

## 3. 색인이 늘어나지 않는 핵심 원인

### 주요 원인 3가지

| 순위 | 원인 | 영향도 | 해결 난이도 |
|------|------|--------|-------------|
| 1 | **신규 사이트 + 대량 콘텐츠** | 높음 | 시간 필요 |
| 2 | **크롤 예산 제한** | 높음 | 중간 |
| 3 | **도메인 권위 부족** | 중간 | 장기적 |

### 상세 설명

#### 1. 신규 사이트 + 대량 콘텐츠
- 85개 게시글이 단기간에 추가됨
- Google은 새 사이트를 신중하게 크롤링
- "발견됨 - 현재 색인이 생성되지 않음" 상태는 **정상**

#### 2. 크롤 예산 제한
- Google은 각 사이트에 크롤 예산 할당
- 새 사이트: 하루 수십 페이지 정도
- 85개 + 카테고리 + 정적 페이지 = 100+ URL
- 전체 크롤링에 수 주 소요 가능

#### 3. 도메인 권위 부족
- 백링크 프로필이 아직 약함
- 브랜드 검색량 낮음
- 소셜 시그널 부족
