# 콘텐츠 검증 가이드

---

## 검증 프로세스 개요

```
1. 콘텐츠 작성 완료
    ↓
2. 공식 출처 확인
    ↓
3. 팩트체크 수행
    ↓
4. 검증 결과 기록
    ↓
5. 수정/보완 (필요시)
    ↓
6. 배포
```

## 검증 시 주의사항

### 필수 확인 항목

1. **연도별 정보**: 2025년 vs 2026년 혼동 주의
2. **금액/수치**: 최신 정보 반영 여부
3. **법률/제도**: 시행일 확인 필수
4. **대상자 기준**: 나이, 소득 기준 정확성

### 신뢰도 높은 출처 우선순위

```
1순위: 정부 공식 사이트 (.go.kr)
2순위: 공공기관 사이트 (.or.kr)
3순위: 공식 보도자료
4순위: 신뢰할 수 있는 언론사
```

### 검증 불가능한 경우

- "~로 알려져 있다", "~라고 한다" 등 불확실한 표현 사용
- 출처 명시 필수
- 추후 확인 필요 표시
