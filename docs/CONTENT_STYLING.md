# 게시글 스타일링 가이드

블로그 게시글 작성 시 활용할 수 있는 디자인 요소들입니다.

---

## 현재 지원 요소

### YouTube 임베드
```markdown
<youtube id="VIDEO_ID" title="영상 제목" />
```

**예시:**
```markdown
<youtube id="dQw4w9WgXcQ" title="넷플릭스 추천 영상" />
```

---

## 추가 가능 요소 (구현 예정)

### 1. 정보 강조 박스 (Callout)

| 유형 | 용도 | 색상 테마 |
|------|------|----------|
| `tip` | 유용한 팁, 추천 정보 | 파랑/청록 |
| `warning` | 주의사항, 경고 | 노랑/주황 |
| `success` | 핵심 포인트, 요약 | 초록 |
| `error` | 피해야 할 것, 금지 | 빨강 |
| `info` | 일반 정보, 참고 | 회색/파랑 |

**마크다운 문법:**
```markdown
<callout type="tip">
여기에 팁 내용을 작성합니다.
</callout>

<callout type="warning">
주의해야 할 내용입니다.
</callout>
```

**활용 예시:**
- 세금 신고 시 주의사항 → `warning`
- 절약 팁 → `tip`
- 핵심 요약 → `success`

---

### 2. 비교 테이블

**용도:** 상품, 서비스, 옵션 비교

**마크다운 문법:**
```markdown
<comparison title="카드 혜택 비교">
| 항목 | A카드 | B카드 | C카드 |
|------|-------|-------|-------|
| 연회비 | 무료 | 1만원 | 3만원 |
| 적립률 | 0.5% | 1% | 1.5% |
| 추천 | 입문자 | 일반 | 헤비유저 |
</comparison>
```

**활용 예시:**
- 보험 상품 비교
- 요금제 비교
- 카드 혜택 비교

---

### 3. 단계별 가이드 (Steps)

**용도:** 절차 설명, 신청 방법, 가이드

**마크다운 문법:**
```markdown
<steps>
1. **첫 번째 단계**: 홈택스에 접속합니다
2. **두 번째 단계**: 로그인 후 신고/납부 메뉴 선택
3. **세 번째 단계**: 부가가치세 신고서 작성
4. **네 번째 단계**: 제출 및 납부
</steps>
```

**활용 예시:**
- 부가세 신고 절차
- 앱 설치 방법
- 서비스 가입 절차

---

### 4. 통계/숫자 강조 블록

**용도:** 중요한 수치, 통계 데이터 강조

**마크다운 문법:**
```markdown
<stat value="83%" label="직장인 비율" description="번아웃을 경험한 직장인" />

<stat-group>
<stat value="15만원" label="월 평균 절약" />
<stat value="92%" label="만족도" />
<stat value="3분" label="소요 시간" />
</stat-group>
```

**활용 예시:**
- 설문조사 결과
- 비용 절감 효과
- 성공률/만족도

---

### 5. FAQ 아코디언

**용도:** 자주 묻는 질문, Q&A

**마크다운 문법:**
```markdown
<faq>
<q>부가세 신고 기한은 언제인가요?</q>
<a>1기: 7월 25일까지, 2기: 다음해 1월 25일까지입니다.</a>

<q>신고 안 하면 어떻게 되나요?</q>
<a>무신고 가산세 20%가 부과됩니다.</a>
</faq>
```

**활용 예시:**
- 세금 관련 FAQ
- 서비스 이용 FAQ
- 제도 설명 FAQ

---

### 6. 인용/출처 블록

**용도:** 공식 정보 인용, 출처 명시

**마크다운 문법:**
```markdown
<quote source="국세청" url="https://nts.go.kr">
2025년 1기 부가가치세 확정신고 기한은 7월 25일까지입니다.
</quote>
```

**활용 예시:**
- 정부 기관 공식 발표
- 법률/규정 인용
- 연구 결과 인용

---

### 7. 요약 박스

**용도:** 글 상단 또는 섹션 요약

**마크다운 문법:**
```markdown
<summary title="3줄 요약">
- 부가세 신고 기한: 1월 25일까지
- 간이과세자도 신고 필수
- 홈택스에서 간편하게 신고 가능
</summary>
```

## 카테고리별 추천 요소

| 카테고리 | 추천 요소 |
|----------|----------|
| 세금/재테크 | FAQ, Steps, Callout(warning), Quote |
| 건강/라이프 | Stat, Callout(tip), Comparison |
| 테크/IT | Steps, Comparison, Callout(info) |
| 보험/금융 | Comparison, FAQ, Stat |
| 가이드/방법 | Steps, Callout, Summary |

## 구현 우선순위

| 순위 | 요소 | 구현 난이도 | 활용 빈도 | 상태 |
|------|------|------------|----------|------|
| 1 | Callout (정보 박스) | 쉬움 | 높음 | 대기 |
| 2 | Steps (단계 가이드) | 쉬움 | 높음 | 대기 |
| 3 | Summary (요약 박스) | 쉬움 | 높음 | 대기 |
| 4 | FAQ (아코디언) | 보통 | 중간 | 대기 |
| 5 | Stat (통계 강조) | 쉬움 | 중간 | 대기 |
| 6 | Quote (인용 블록) | 쉬움 | 중간 | 대기 |
| 7 | Comparison (비교표) | 보통 | 중간 | 대기 |

## 스타일링 원칙

1. **일관성**: 동일한 유형의 정보는 동일한 요소 사용
2. **간결함**: 요소 남용 금지, 페이지당 3-5개 적정
3. **접근성**: 색상만으로 정보 전달하지 않기
4. **모바일**: 모바일에서도 잘 보이는 디자인
