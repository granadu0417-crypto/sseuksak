# AI 디지털교과서 완벽 가이드: 2026년 학부모가 알아야 할 핵심 정보

"우리 아이 학교에서 태블릿으로 수업한다는데, 괜찮은 걸까요?"

2025년 3월부터 전국 학교에 **AI 디지털교과서**가 도입되었습니다. 기존 종이 교과서와 함께 디지털 기기를 활용한 새로운 학습 방식이 시작된 것입니다.

오늘은 AI 디지털교과서의 **모든 것**을 학부모 관점에서 정리해드릴게요!

---

## AI 디지털교과서란?

### 기본 개념

> **인공지능 기술을 활용해 학생 개인별 맞춤 학습을 지원하는 디지털 교과서**

기존 디지털교과서는 단순히 종이책을 전자책으로 옮긴 것이었습니다. AI 디지털교과서는 여기에 **인공지능**이 더해져 학생 개개인의 수준에 맞는 학습을 제공합니다.

### 기존 교과서와 비교

| 구분 | 종이 교과서 | 기존 디지털교과서 | AI 디지털교과서 |
|------|------------|------------------|----------------|
| 형태 | 책 | 전자책 | AI 탑재 플랫폼 |
| 내용 | 고정 | 고정 + 멀티미디어 | **개인별 맞춤** |
| 학습 분석 | 없음 | 제한적 | **실시간 AI 분석** |
| 피드백 | 교사 의존 | 일부 자동화 | **AI 즉시 피드백** |
| 진도 | 학급 동일 | 학급 동일 | **개인별 조절** |

## 도입 일정 및 적용 과목

### 단계별 도입

| 연도 | 적용 대상 | 과목 |
|------|----------|------|
| **2025년 3월** | 초3~4, 중1, 고1 | 영어, 수학, 정보 |
| **2026년 3월** | 초5~6, 중2, 고2 | 영어, 수학, 정보 |
| **2027년** | 전학년 | 영어, 수학, 정보 + **국어, 사회, 과학 추가** |
| **2028년** | 전학년 확대 | 대부분 과목 |

> ⚠️ **변경 안내**: 당초 2026년에 도입 예정이었던 국어, 사회, 과학 과목은 **2027년으로 연기**되었습니다.

### 2026년 주요 변화

- **적용 학년 확대**: 초5~6, 중2, 고2 추가
- **적용 과목**: 영어, 수학, 정보 (2025년과 동일)
- **국어, 사회, 과학**: 2027년으로 연기
- **기존 학년 안정화**: 2025년 도입 학년 2년차 진입

## AI 디지털교과서의 주요 기능

### 1. 맞춤형 학습 콘텐츠

학생의 학습 수준에 따라 **다른 문제와 설명**이 제공됩니다.

| 학습 수준 | 제공 콘텐츠 |
|----------|-----------|
| 기초 부족 | 기초 개념 복습, 쉬운 문제 |
| 보통 수준 | 표준 학습 경로 |
| 심화 가능 | 도전 문제, 확장 학습 |

### 2. 실시간 학습 분석

AI가 학습 과정을 분석해 **즉각적인 피드백** 제공:

- 오답 원인 분석
- 취약 단원 파악
- 학습 시간 및 패턴 분석
- 집중도 측정

### 3. 대시보드 기능

**학생용 대시보드**:
- 나의 학습 진도
- 성취도 그래프
- 추천 학습 활동
- 목표 달성 현황

**교사용 대시보드**:
- 학급 전체 학습 현황
- 개인별 취약점 파악
- 수업 설계 지원
- 학부모 상담 자료

### 4. 다양한 학습 자료

| 유형 | 예시 |
|------|------|
| 동영상 | 개념 설명, 실험 영상 |
| 시뮬레이션 | 과학 실험, 수학 그래프 |
| 게임형 학습 | 퀴즈, 미션 수행 |
| VR/AR | 역사 탐방, 과학 관찰 |

### 5. AI 튜터 기능

학생이 모르는 부분을 질문하면 **AI가 설명**해줍니다:

- 24시간 질문 가능
- 수준에 맞는 설명
- 다양한 풀이 방법 제시
- 관련 개념 연결 학습

## 수업 방식의 변화

### 기존 수업 vs AI 디지털교과서 수업

| 구분 | 기존 수업 | AI 디지털교과서 수업 |
|------|----------|-------------------|
| 도입 | 전체 개념 설명 | 영상/자료로 선행 학습 |
| 전개 | 동일 문제 풀이 | **수준별 맞춤 활동** |
| 정리 | 전체 오답 해설 | **개인별 피드백** |
| 과제 | 동일 숙제 | **AI 추천 학습** |

### 실제 수업 예시

**예: 수학 방정식 수업**

1. **사전 학습** (가정): AI 제공 영상으로 개념 예습
2. **확인 활동** (학교): AI 진단으로 이해도 확인
3. **수준별 학습** (학교):
   - A그룹: 심화 문제
   - B그룹: 표준 문제
   - C그룹: 기초 보충
4. **협력 활동** (학교): 그룹별 토론, 발표
5. **정리 학습** (가정): AI 추천 복습

## 학부모가 꼭 알아야 할 것

### 디지털 기기 관련

#### 기기 지급 방식

| 방식 | 설명 |
|------|------|
| 학교 대여 | 등교 시 수령, 하교 시 반납 |
| 개인 소유 | 가정에서 구매한 기기 사용 가능 |
| 혼합 | 일부 학교에서 선택 가능 |

**대부분의 학교는 학교 대여 방식**을 사용합니다.

#### 기기 사양

- **권장 기기**: 태블릿PC (아이패드, 갤럭시탭, 크롬북 등)
- **화면 크기**: 10인치 이상 권장
- **인터넷**: 학교 Wi-Fi 제공

### 시력 및 건강 관리

#### 학교 지침

| 항목 | 권장 사항 |
|------|----------|
| 연속 사용 | 30분 사용 후 5분 휴식 |
| 화면 거리 | 30cm 이상 유지 |
| 조명 | 적절한 밝기 유지 |
| 자세 | 바른 자세로 학습 |

#### 가정에서 관리

- [ ] 디지털 기기 사용 시간 모니터링
- [ ] 정기적인 시력 검사
- [ ] 야외 활동 시간 확보
- [ ] 취침 전 기기 사용 제한

### 개인정보 보호

#### 수집되는 정보

| 유형 | 예시 |
|------|------|
| 학습 데이터 | 문제 풀이 결과, 학습 시간 |
| 행동 데이터 | 클릭 패턴, 페이지 체류 시간 |
| 성취 데이터 | 점수, 성취도, 진도율 |

#### 보호 조치

- **익명화 처리**: 개인 식별 불가능하게 처리
- **접근 제한**: 담당 교사, 학생 본인만 열람
- **보관 기간**: 졸업 후 일정 기간 후 삭제
- **제3자 제공 금지**: 외부 기관에 제공 불가

## 자주 묻는 질문 (FAQ)

### Q1. 종이 교과서는 없어지나요?

**아니요, 병행 사용합니다.**

- AI 디지털교과서와 종이 교과서 함께 사용
- 일부 과목/활동은 여전히 종이 교과서 위주
- 학교별로 활용 비율 다름

### Q2. 집에서도 AI 교과서를 볼 수 있나요?

**네, 가능합니다.**

- 개인 기기에서 로그인하여 접속
- 복습, 숙제 등에 활용
- 인터넷 연결 필수

### Q3. 아이가 게임만 하면 어떡하죠?

**학습용 앱만 설치됩니다.**

- 교육청에서 관리하는 기기 사용
- 게임/SNS 등 비교육용 앱 차단
- 학습 외 사이트 접근 제한

### Q4. 인터넷이 안 되면 수업이 안 되나요?

**오프라인 학습도 가능합니다.**

- 미리 콘텐츠 다운로드 가능
- 일부 기능은 오프라인에서도 작동
- 학교 Wi-Fi 환경 보강 중

### Q5. 성적에 어떻게 반영되나요?

**기존 평가 방식과 동일합니다.**

- AI 분석 결과 ≠ 성적
- 수행평가, 시험으로 공식 평가
- AI 데이터는 학습 보조 자료

### Q6. 선생님 역할은 줄어드나요?

**오히려 역할이 더 중요해집니다.**

- AI는 도구, 선생님이 교육의 주체
- 데이터 기반 맞춤 지도 가능
- 상담, 인성교육 등 심화 역할

## 정리: 핵심 포인트

### 꼭 기억할 것

1. **2025년 3월부터** 단계적 도입, **2026년 학년 확대**
2. **2026년 과목**: 영어, 수학, 정보 (국어, 사회, 과학은 2027년)
3. 종이 교과서와 **병행 사용**
4. **맞춤형 학습**이 가장 큰 장점
5. **시력 관리**와 **사용 시간 관리** 필수
6. 개인정보는 **철저히 보호**

### 학부모 역할

- 제도를 **이해**하고 자녀와 대화
- 건강한 디지털 **습관** 형성 지원
- 학교와 **소통**하며 정보 파악
- 과도한 기대나 우려보다 **균형** 잡힌 시각

## 마무리

AI 디지털교과서는 **교육의 큰 변화**입니다.

무조건 좋다거나, 무조건 걱정된다는 시각보다 **균형 잡힌 이해**가 필요합니다.

중요한 것은:
1. **자녀와 대화**하며 학교 생활 파악하기
2. **건강한 디지털 습관** 함께 만들기
3. **학교와 협력**하여 적응 지원하기

새로운 교육 환경에서 자녀가 잘 적응할 수 있도록 함께 준비해 나가시길 바랍니다!
