전세 2억을 대출받으면 월 이자가 58만원이다. 같은 집을 월세로 살면 보증금 2천만원에 월세 95만원. 매달 37만원 차이, 1년이면 444만원이다. 그런데 월세 세액공제를 받으면 격차가 줄어든다. 반대로 전세대출 이자가 올라가면 월세가 더 싸지는 역전도 일어난다. 결국 내 보증금 규모, 대출 금리, 세제 혜택까지 넣고 계산해야 답이 나온다.

## 전세 = 무조건 이득? 2026년은 다르다

전세가 무조건 유리하던 시대는 끝났다. 이유는 세 가지다.

첫째, 금리가 올랐다. 한국은행 기준금리가 2.5%이고 시중 전세대출 금리는 3.5~4.5% 수준이다. 전세 보증금을 전액 대출받으면 매달 나가는 이자가 만만치 않다.

둘째, 월세 비중이 역대 최고다. 2025년 전국 전월세 계약 중 월세 비중이 56.5%를 기록했다(iM증권 리포트). 반전세(보증부 월세)가 보편화되면서 전세와 월세의 경계가 흐려졌다.

셋째, 전세사기 공포가 남아있다. 2023년 HUG가 집주인 대신 세입자에게 지급한 보증사고 금액만 1조 565억원이었다. 보증금을 줄이고 월세를 내는 게 심리적으로 안전하다고 느끼는 사람이 늘었다.

그래서 지금은 감으로 고르는 게 아니라 숫자로 비교해야 한다.

## 판단 공식: 전월세전환율 vs 전세대출 금리

전세와 월세 중 어디가 유리한지 판단하는 핵심 공식은 이것이다.

> **전월세전환율 > 내 전세대출 금리 → 전세가 유리**
> **전월세전환율 < 내 전세대출 금리 → 월세가 유리**

전월세전환율이란 전세 보증금을 월세로 바꿀 때 적용하는 연 이율이다. 2026년 상반기 한국주택금융공사(HF)가 공시한 전월세전환율은 **6.4%**다(통계청 국가통계포털 최근 6개월 평균, 2026.1.2 시행).

내 전세대출 금리가 3.5%라면? 전환율 6.4%가 훨씬 높으니 전세가 유리하다. 같은 보증금을 월세로 전환하면 6.4% 이율이 적용돼 월세가 비싸지기 때문이다. 반대로 전세대출 금리가 7%까지 올라간다면 월세가 더 싸다.

법정 전월세전환율 상한은 **기준금리 + 2.0%**다(주택임대차보호법 제7조의2). 2026년 기준금리 2.5% 기준으로 상한은 **4.5%**다. 재계약 시 집주인이 이 이상의 전환율을 요구하면 거부할 수 있다.

전월세전환율 계산법이 궁금하다면 [전월세 전환율 계산법 가이드](/posts/rent-conversion-rate-guide-2026)에서 자세히 다뤘다.

## 은행별 전세대출 금리 비교 (2026년 기준)

전세대출 금리는 은행마다 다르다. 한국주택금융공사가 공시한 최신 금리는 다음과 같다.

### 시중은행 전세대출 금리

| 은행 | 금리(연) | 문의 |
|------|----------|------|
| 국민은행 | 3.50% | 1644-9999 |
| 카카오뱅크 | 3.73% | 1599-3333 |
| 케이뱅크 | 3.85% | 1522-1000 |
| 토스뱅크 | 3.93% | 1661-7654 |

*출처: 한국주택금융공사 전세대출금리안내(월별 공시)*

### 정부지원 전세대출 금리

| 상품 | 금리(연) | 대상 |
|------|----------|------|
| 청년 버팀목 | 1.5~2.7% | 만 19~34세, 연소득 5천만원 이하 |
| 일반 버팀목 | 2.5~2.9% | 무주택 세대주, 연소득 5천만원 이하 |
| 신혼부부 전세 | 1.5~2.7% | 혼인 7년 이내, 합산소득 6천만원 이하 |

*출처: 주택도시기금 상품안내*

정부지원 대출 자격이 된다면 금리 2%대로 전세 살 수 있다. 이 경우 전월세전환율(6.4%)과 격차가 크기 때문에 전세가 압도적으로 유리하다.

전세대출을 이미 받은 상태에서 금리를 낮추고 싶다면 [대환대출 갈아타기 가이드](/posts/loan-refinancing-guide-2026)를 참고하자.

## 보증금별 전세 이자 vs 월세 실비용 비교

이제 실제 숫자로 비교한다. 전세대출 금리 3.5%(국민은행 기준), 전월세전환율 6.4%(HF 공시)를 적용했다. 월세는 보증금 없이 전액 월세로 전환한 금액이다.

### 전액 대출 시 월 비용 비교

| 보증금 | 전세 월이자 | 월세 환산액 | 차이 | 연간 차이 |
|--------|------------|------------|------|----------|
| 1억 | 29.2만원 | 53.3만원 | -24.1만원 | -289만원 |
| 2억 | 58.3만원 | 106.7만원 | -48.4만원 | -580만원 |
| 3억 | 87.5만원 | 160.0만원 | -72.5만원 | -870만원 |
| 5억 | 145.8만원 | 266.7만원 | -120.9만원 | -1,450만원 |

*전세 월이자 = 보증금 x 3.5% / 12, 월세 환산 = 보증금 x 6.4% / 12*

보증금 3억 기준으로 전세대출 이자는 월 87.5만원, 같은 집을 월세로 전환하면 월 160만원이다. 전세가 연간 870만원 저렴하다.

### 실전 시나리오: 보증금 3억 아파트

현실에서는 전세금 전액을 대출받지 않는다. 보증금 3억 아파트를 자기자금 6천만원 + 대출 2.4억으로 계약한다고 가정하자.

| 항목 | 전세 | 월세 (보증금 3천/월 120만) |
|------|------|--------------------------|
| 자기자금 투입 | 6,000만원 | 3,000만원 |
| 월 고정 지출 | 70만원 (대출이자) | 120만원 (월세) |
| 연간 지출 | 840만원 | 1,440만원 |
| 세제 혜택 | 소득공제 ~56만원 | 세액공제 ~122만원 |
| **실질 연간 비용** | **784만원** | **1,318만원** |
| 여유 자금 | 0원 | 3,000만원 |

전세가 실질 연간 534만원 저렴하다. 다만 월세를 선택하면 3천만원의 여유 자금이 생긴다. 이 돈을 연 10% 이상 수익률로 굴릴 수 있다면 월세도 나쁘지 않다.

더 정밀한 시뮬레이션을 해보고 싶다면 [주거비용 시뮬레이터](/tools/housing-cost-simulator)에서 내 조건을 직접 입력해볼 수 있다.

## 세금 혜택 비교: 월세 세액공제 vs 전세대출 소득공제

세금 혜택까지 포함하면 실질 비용이 달라진다.

### 월세 세액공제 (2026년)

| 항목 | 내용 |
|------|------|
| 대상 | 총급여 8,000만원 이하 무주택 세대주 |
| 공제율 | 총급여 5,500만원 이하: **17%** / 초과: **15%** |
| 한도 | 연 **1,000만원** (2026년 확대) |
| 방식 | 세액공제 (세금에서 직접 차감) |

*출처: 조세특례제한법 제95조의2*

### 전세대출 소득공제

| 항목 | 내용 |
|------|------|
| 대상 | 무주택 세대주, 국민주택규모 이하 |
| 공제율 | 원리금 상환액의 **40%** |
| 한도 | 연 **400만원** |
| 방식 | 소득공제 (과세표준에서 차감) |

*출처: 소득세법 제52조*

### 연봉별 실환급액 비교

같은 주거비를 쓸 때 세금으로 얼마나 돌려받는지 비교했다.

| 연봉 | 월세 세액공제 | 전세대출 소득공제 | 월세가 유리 |
|------|-------------|-----------------|------------|
| 3,000만원 | 월세 70만 x 12 = 840만 x 17% = **142.8만원** | 원리금 840만 x 40% = 336만 x 세율 6% = **20.2만원** | +122.6만원 |
| 5,000만원 | 월세 70만 x 12 = 840만 x 17% = **142.8만원** | 원리금 840만 x 40% = 336만 x 세율 15% = **50.4만원** | +92.4만원 |
| 7,000만원 | 월세 70만 x 12 = 840만 x 15% = **126만원** | 원리금 840만 x 40% = 336만 x 세율 24% = **80.6만원** | +45.4만원 |

월세 세액공제가 전세대출 소득공제보다 환급액이 크다. 특히 저소득 구간에서 차이가 벌어진다. 다만 이것만으로 월세가 유리하다고 볼 수는 없다. 세제 혜택 차이보다 월세와 전세의 절대 비용 차이가 훨씬 크기 때문이다.

월세 세액공제 신청 방법은 [월세 세액공제 가이드](/posts/monthly-rent-tax-credit)에서 확인할 수 있다.

## 상황별 판단 가이드

계산이 복잡하니 상황별로 정리했다.

### 전세가 유리한 경우

| 조건 | 이유 |
|------|------|
| 전세대출 금리 4% 이하 | 전환율(6.4%)보다 낮아 월비용 절감 |
| 정부지원 대출 가능 | 금리 1.5~2.9%면 압도적으로 유리 |
| 2년 이상 장기 거주 | 이사 비용 대비 절약 효과 극대화 |
| 아파트 + 보증보험 가입 가능 | 보증금 반환 리스크 최소화 |
| 목돈 투자처 없음 | 보증금 묶어둬도 기회비용 낮음 |

### 월세가 유리한 경우

| 조건 | 이유 |
|------|------|
| 전세대출 금리 6% 이상 | 전환율과 비슷하거나 역전 |
| 빌라/다세대 (깡통전세 위험) | 보증금 안전이 최우선 |
| 1년 미만 단기 거주 | 전세 이사비+보증보험료 대비 월세가 경제적 |
| 여유자금 투자수익률 > 전환율 | 보증금 줄이고 투자 수익으로 월세 충당 |
| 연봉 5,500만원 이하 | 세액공제 17%로 실질 월세 부담 감소 |

### 반전세가 유리한 경우

전세대출 한도가 부족하거나, 보증금을 줄여 전세사기 리스크는 낮추되 월세 부담도 줄이고 싶을 때다. 보증금 5천만원~1억에 월세 30~60만원 수준의 반전세가 양쪽의 장점을 취하는 절충안이다.

## 전세 선택 시 꼭 확인할 3가지

전세가 유리하다고 결론 났더라도, 안전 확인 없이 계약하면 보증금을 잃을 수 있다.

**1. 전세보증보험 가입 가능 여부**

HUG, HF, SGI 중 하나라도 보증보험에 가입할 수 있는 매물인지 확인한다. 가입이 안 되는 집은 피하는 게 안전하다. 보증보험 기관별 차이는 [전세보증보험 비교 가이드](/posts/jeonse-deposit-guarantee-insurance-2026)에서 정리했다.

**2. 전세가율 확인**

전세가율(전세가 / 매매가)이 70%를 넘으면 깡통전세 위험이 있다. 등기부등본에서 근저당 설정액을 확인하고, (근저당 + 전세금)이 매매가를 초과하는지 반드시 체크한다.

**3. 등기부등본 + 세금 체납 확인**

등기부등본에서 근저당, 가압류, 임차권등기 여부를 확인한다. 2026년 현재 집주인 동의 없이도 미납 국세를 열람할 수 있으니 주민센터에서 열람하자.

## 자주 묻는 질문

**반전세는 언제 유리한가요?**

전세대출 한도가 부족하거나, 전세 보증금을 줄여 리스크를 낮추고 싶을 때 유리하다. 보증금을 최우선변제금(서울 5,500만원) 이내로 설정하면 보증금 보호가 강화된다.

**전세대출 금리를 낮추는 방법이 있나요?**

대환대출(갈아타기)로 더 낮은 금리의 상품으로 교체할 수 있다. 2025년 중도상환수수료가 인하돼 갈아타기 비용이 줄었다. 자세한 내용은 [대환대출 갈아타기 가이드](/posts/loan-refinancing-guide-2026)를 참고하자.

**월세 세액공제와 현금영수증 중복 가능한가요?**

아니다. 월세 세액공제를 받으면 같은 금액에 대해 현금영수증 소득공제를 중복 적용할 수 없다. 일반적으로 세액공제가 더 유리하다.

**전월세전환율 상한을 초과해서 요구하면 어떻게 하나요?**

재계약(갱신) 시 법정 상한은 기준금리 + 2.0% = 4.5%다. 상한을 초과하는 월세 인상을 요구받으면 주택임대차보호법 제7조의2를 근거로 거부할 수 있다. 신규 계약에는 상한이 적용되지 않으니 주의하자.

**묵시적 갱신 시 전세/월세 조건은 어떻게 되나요?**

기존 계약과 동일한 조건으로 2년 연장된다. 세입자는 언제든 해지 통보 가능하고, 통보 후 3개월 뒤 효력이 발생한다. 임대인은 갱신 거절 사유가 없는 한 거부할 수 없다.
