2026년 연말정산 간소화 서비스가 **1월 15일**에 오픈합니다! 국세청 공식 자료를 바탕으로 이용방법을 상세히 정리했습니다.

## 연말정산 간소화 서비스란?

### 정의

> **은행, 학교, 병원 등 영수증 발급기관이 제출한 소득·세액공제 증명서류를 국세청이 DB로 구축하여 근로자에게 제공하는 서비스**

쉽게 말해, 각종 공제 자료를 **한 곳에서 조회·출력**할 수 있는 시스템입니다.

### 왜 간소화 서비스가 필요한가요?

| 간소화 서비스 이전 | 간소화 서비스 이후 |
|------------------|------------------|
| 카드사, 병원, 학교 개별 방문 | 홈택스에서 한 번에 조회 |
| 수십 장의 영수증 수집 | PDF 1개로 다운로드 |
| 누락 위험 높음 | 자동으로 모든 자료 수집 |
| 수일 소요 | 5분 완료 |

## 간소화 서비스 이용방법 (단계별)

### STEP 1: 홈택스 접속

1. **홈택스 접속**: [www.hometax.go.kr](https://www.hometax.go.kr)
2. **메뉴 선택**: 장려금·연말정산·기부금 → 연말정산간소화

### STEP 2: 로그인

| 인증 방법 | 설명 |
|----------|------|
| 공동인증서 | 기존 공인인증서 |
| 금융인증서 | 은행 발급 인증서 |
| 간편인증 | 카카오, 네이버, PASS 등 |
| 생체인증 | 지문, 얼굴인식 (모바일) |

### STEP 3: 자료 조회

1. **귀속연도 선택**: 2025년
2. **조회 버튼 클릭**: 각 항목별 또는 한 번에 조회
3. **부양가족 선택**: 자료 포함 여부 체크

### STEP 4: 자료 내려받기 (PDF)

1. **한 번에 내려받기** 클릭
2. **제출용 파일** 선택
3. PDF 파일 저장

### STEP 5: 회사 제출

| 제출 방법 | 설명 |
|----------|------|
| PDF 제출 | 회사 연말정산 시스템에 업로드 |
| 출력 제출 | 종이로 인쇄하여 제출 |
| 온라인 제출 | 홈택스 '편리한 연말정산' 이용 |

### 유형 3: 간편제출 (온라인 자료 제출)

## 부양가족 자료제공 동의

### 왜 필요한가요?

부양가족(배우자, 부모님, 자녀 등)의 공제 자료를 조회하려면 **사전 동의**가 필요합니다.

### 동의 방법

#### 방법 1: 홈택스 온라인 동의

1. 부양가족이 직접 홈택스 로그인
2. 연말정산간소화 → 부양가족 자료제공 동의
3. 근로자(본인) 정보 입력
4. 동의 완료

#### 방법 2: 세무서 방문

1. 부양가족 신분증 지참
2. 관할 세무서 방문
3. 동의서 작성 후 제출

#### 방법 3: 우편/팩스 신청

1. [국세청 홈페이지](https://www.nts.go.kr)에서 동의서 양식 다운로드
2. 작성 후 관할 세무서에 우편/팩스 발송

### 동의 관련 주의사항

| 주의사항 | 설명 |
|----------|------|
| 매년 갱신 불필요 | 한 번 동의하면 매년 자동 적용 |
| 동의 철회 가능 | 언제든 홈택스에서 철회 가능 |
| 개인정보 보호 | 총급여 등 상세 정보는 제공 안 됨 |
| 중복 확인 | 여러 자녀가 부모님 공제 시 사전 협의 |

## 일괄제공 서비스

### 일괄제공 서비스란?

> **회사가 근로자 동의를 받아 간소화 자료를 일괄 수집하는 서비스**

근로자가 개별적으로 자료를 제출할 필요 없이, 회사에서 한 번에 처리합니다.

### 이용 조건

| 조건 | 설명 |
|------|------|
| 회사 신청 | 회사가 일괄제공 서비스 신청 |
| 근로자 동의 | 근로자가 홈택스에서 동의 |
| 동의 기한 | 회사별 상이 (보통 1월 중순) |

### 일괄제공 서비스 일정 (2025년 귀속)

| 일정 | 내용 |
|------|------|
| 2025.11 ~ 2026.1.10 | 회사 근로자 명단 등록 |
| 2026.1.1 ~ 1.19 | 근로자 동의 기간 |
| 2026.1.20 ~ | 회사에 자료 일괄 제공 |

### 동의 방법

1. 홈택스 로그인
2. 연말정산간소화 → 일괄제공 동의
3. 소속 회사 확인
4. 동의 버튼 클릭

## 맞벌이 절세 안내

### 기능 소개

맞벌이 부부의 경우, **누가 어떤 공제를 받을지**에 따라 세금이 달라집니다.

### 이용 방법

1. 부부 모두 공제신고서 작성
2. 배우자 '제공동의' 필요
3. '맞벌이 절세 안내' 서비스 이용
4. 최적의 공제 조합 확인

### 주의사항

- 배우자 총급여 등 상세 정보는 제공되지 않음 (개인정보 보호)
- 부부 모두 공제신고서를 작성해야 이용 가능

## 자주 하는 실수 & 해결방법

### 실수 1: 부양가족 동의 누락

**증상**: 부양가족 자료가 조회되지 않음

**해결**:
- 부양가족이 직접 홈택스에서 동의
- 또는 세무서 방문하여 동의서 제출

### 실수 2: 중복 공제

**증상**: 형제가 동일한 부모님을 공제

**해결**:
- 사전에 가족 간 협의
- 한 명만 공제 신청
- 중복 시 가산세 발생 주의

### 실수 3: 조회되지 않는 자료 누락

**증상**: 월세, 해외 교육비 등 미반영

**해결**:
- 해당 자료는 직접 수집하여 제출
- 임대차계약서, 영수증 등 증빙 준비

### 실수 4: 잘못된 연도 조회

**증상**: 이전 연도 자료를 제출

**해결**:
- 귀속연도 '2025년' 정확히 선택
- 다운로드 파일명에 연도 확인

### 실수 5: 회사 제출 기한 놓침

**증상**: 연말정산에 반영 안 됨

**해결**:
- 5월 종합소득세 신고 시 직접 반영
- 경정청구로 환급 신청 가능

## 간소화 서비스 Q&A

### Q1. 1월 15일 전에 접속하면 안 되나요?

**서비스가 열려 있지 않습니다.**

- 1월 15일 오전 8시부터 이용 가능
- 그 전에는 메뉴가 비활성화

### Q2. 모바일에서도 이용 가능한가요?

**네, 가능합니다.**

- 홈택스 앱 또는 모바일 웹
- 손택스 앱에서도 이용 가능

### Q3. 자료가 잘못 조회되면 어떻게 하나요?

**조회되지 않는 의료비 신고센터를 이용하세요.**

- 홈택스 → 연말정산간소화 → 조회되지 않는 의료비
- 직접 신고하면 반영됩니다

### Q4. 외국인도 이용 가능한가요?

**네, 가능합니다.**

- 외국인등록번호로 홈택스 가입
- 동일하게 간소화 서비스 이용

### Q5. 공무원/교원도 같은 방법인가요?

**동일합니다.**

- 소속 기관 연말정산 시스템 이용
- 간소화 자료는 홈택스에서 동일하게 조회
