## 청년도약계좌

> ⚠️ **중요 안내**: 청년도약계좌 신규 가입은 **2025년 12월 31일부로 종료**되었습니다. 기존 가입자는 만기까지 정상 운영됩니다. 2026년 6월부터 후속 상품인 **청년미래적금**이 출시될 예정입니다.

### 제도 개요 (기존 가입자 해당)

> **5년간 매월 저축하면 정부가 기여금을 더해 최대 5,000만 원 달성**

| 항목 | 내용 |
|------|------|
| 가입 기간 | 5년 (60개월) |
| 월 납입액 | 40만~70만 원 |
| 정부 기여금 | 월 최대 3.3만 원 (2024년 7월 개편) |
| 이자 | 비과세 |
| 만기 수령액 | **최대 5,000만 원** |
| **신규가입** | ❌ 2025.12.31 종료 |

### 가입 자격

| 조건 | 내용 |
|------|------|
| 나이 | 만 19세~34세 |
| 소득 | 개인소득 7,500만 원 이하 |
| 가구소득 | 중위소득 250% 이하 |
| 금융소득 | 연 2,000만 원 이하 |

### 정부 기여금 체계 (2024년 7월 개편 적용)

| 개인소득 | 정부 기여금 (월) |
|----------|------------------|
| 2,400만 원 이하 | **3.3만 원** |
| 3,600만 원 이하 | 2.9만 원 |
| 4,800만 원 이하 | 2.3만 원 |
| 6,000만 원 이하 | 1.7만 원 |
| 7,500만 원 이하 | 1.0만 원 |

### 예상 수령액 계산 (기존 가입자)

**월 70만 원 × 60개월 + 정부 기여금 + 이자**

| 개인소득 | 본인 납입 | 정부 기여금 | 이자 (예상) | **총 수령액** |
|----------|----------|------------|------------|--------------|
| 2,400만 원 이하 | 4,200만 원 | 198만 원 | 약 700만 원 | **약 5,098만 원** |
| 4,800만 원 이하 | 4,200만 원 | 138만 원 | 약 700만 원 | **약 5,038만 원** |

### 가입 안내

> ❌ **신규 가입 불가** - 2025년 12월 31일 종료

기존 가입자는 만기까지 정상 운영됩니다. 취급 은행: 국민, 신한, 하나, 우리, 농협, 기업 등

## 청년월세지원

### 제도 개요

> **월세 부담을 덜어주는 월 최대 20만 원 지원**

| 항목 | 내용 |
|------|------|
| 지원 금액 | 월 최대 20만 원 |
| 지원 기간 | 최대 12개월 |
| 총 지원액 | **최대 240만 원** |

### 지원 자격

> **2026년부터 상시화**: 기존 한시 사업에서 상시 지원 체계로 전환되어 언제든 신청 가능

| 조건 | 내용 |
|------|------|
| 나이 | 만 19세~34세 (1986~2007년생) |
| 청년 소득 | 중위소득 60% 이하 (1인 가구 기준 약 134만 원) |
| 원가구 소득 | 중위소득 100% 이하 (3인 가구 기준 약 471만 원) |
| 재산 | 1.3억 원 이하 |
| 차량 | 시가 2,500만 원 미만 |
| 주거 형태 | 월세 거주, 무주택자, 공공임대주택 제외 |

### 신청 방법

1. **복지로** (www.bokjiro.go.kr) 접속
2. 청년월세 한시 특별지원 검색
3. 온라인 신청
4. 서류 제출 (임대차계약서, 계좌이체 내역)
5. 심사 후 지급

### 주의사항

- 임대차계약서 상 본인 명의 필수
- 실제 거주 확인
- 공공임대주택 거주자 제외
- 부모와 동거 시 제외
