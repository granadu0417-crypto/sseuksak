2026년 1월, **전자정부법 개정안**이 국회를 통과하며 모바일 신분증이 실물 신분증과 **완전히 동일한 법적 효력**을 갖게 되었습니다.

| 구분 | 내용 |
|------|------|
| 발급 비용 | **무료** |
| 발급 방법 | IC 태그 또는 QR 코드 |
| 법적 효력 | 실물 신분증과 **동일** |
| 발급 앱 | 대한민국 모바일 신분증 (+ 민간 앱) |

> 이제 스마트폰 하나로 은행, 병원, 관공서, 편의점까지 모든 곳에서 신분 확인이 가능합니다.

## 1. 모바일 신분증이란?

모바일 신분증은 스마트폰에 저장되는 **디지털 신분증**입니다. 블록체인 기반 DID(분산신원인증) 기술로 보안성이 높고, 실물 신분증과 동일한 법적 효력을 가집니다.

### 발급 가능한 모바일 신분증 7종

| 신분증 종류 | 발급 가능 여부 | 비고 |
|------------|---------------|------|
| 주민등록증 | O | 만 17세 이상 |
| 운전면허증 | O | 면허 소지자 |
| 장애인등록증 | O | 2026.1.22 전국 확대 |
| 국가보훈등록증 | O | 보훈 대상자 |
| 외국인등록증 | O | 국내 거주 외국인 |
| 재외국민신원확인증 | O | 재외국민 |
| 국가기술자격증 | O | 자격증 소지자 |

**공식 사이트**: [mobileid.go.kr](https://www.mobileid.go.kr)

## 2. 발급 방법 비교 (IC vs QR)

모바일 신분증은 **두 가지 방법**으로 발급받을 수 있습니다.

### 방법 A: IC 태그 방식 (비대면 재발급 가능)

| 단계 | 내용 |
|------|------|
| 1 | IC칩 내장 실물 신분증 발급 (주민센터/면허시험장) |
| 2 | '대한민국 모바일 신분증' 앱 설치 |
| 3 | 본인인증 진행 |
| 4 | IC 신분증을 스마트폰 뒷면에 태그 |
| 5 | 발급 완료 |

**장점**: 스마트폰 교체 시 **재방문 없이** IC 태그만으로 재발급 가능

### 방법 B: QR 코드 방식 (현장 즉시 발급)

| 단계 | 내용 |
|------|------|
| 1 | 실물 신분증 지참 후 주민센터 방문 |
| 2 | 모바일 신분증 발급 신청서 작성 |
| 3 | '대한민국 모바일 신분증' 앱 설치 |
| 4 | 담당자가 제시한 QR 코드 스캔 |
| 5 | 안면 인식 후 발급 완료 |

**장점**: IC 신분증 없이도 **즉시 발급** 가능

### IC vs QR 비교표

| 구분 | IC 태그 방식 | QR 코드 방식 |
|------|-------------|-------------|
| 최초 발급 | 주민센터/면허시험장 방문 필요 | 주민센터 방문 필요 |
| 재발급 (폰 교체) | **비대면 가능** (IC 태그) | 재방문 필요 |
| 필요 조건 | IC칩 내장 신분증 | 실물 신분증 |
| 추천 대상 | 스마트폰 자주 바꾸는 분 | IC 신분증 없는 분 |

> **추천**: 장기적으로 편리한 **IC 태그 방식**을 권장합니다.

## 3. IC 주민등록증 발급 방법

모바일 주민등록증을 IC 태그 방식으로 발급받으려면, 먼저 **IC 주민등록증**이 필요합니다.

### 발급 절차

| 단계 | 내용 |
|------|------|
| 1 | 가까운 주민센터 방문 |
| 2 | IC 주민등록증 발급 신청서 작성 |
| 3 | 신분 확인 및 사진 촬영 |
| 4 | 약 2주 후 수령 |

### 발급 비용

| 구분 | 비용 |
|------|------|
| 기존 주민등록증 반납 시 | **5,000원** |
| 기존 주민등록증 미반납 시 | **10,000원** |

> IC 주민등록증은 기존 플라스틱 주민등록증과 외관은 동일하지만, **IC칩이 내장**되어 있습니다.

## 5. 실제 사용처

모바일 신분증은 실물 신분증이 필요한 **거의 모든 곳**에서 사용 가능합니다.

### 사용 가능 장소

| 장소 | 사용 가능 여부 | 예시 |
|------|---------------|------|
| 관공서 | **O** | 주민센터, 구청, 법원 |
| 금융기관 | **O** | 은행 계좌 개설, 대출 신청 |
| 병원/약국 | **O** | 진료 접수, 처방전 수령 |
| 편의점/마트 | **O** | 주류/담배 성인 인증 |
| 공유 서비스 | **O** | 킥보드, 자전거, 카셰어링 |
| 통신사 | **O** | 휴대폰 개통 |
| 항공/철도 | **O** | 국내선 탑승, KTX 할인 |

### 아직 사용 불가한 곳

| 장소 | 사용 불가 사유 |
|------|---------------|
| 해외 | 국내 전용 (국제 협약 미체결) |

## 6. 보안 및 분실 대처

### 모바일 신분증 보안 기술

| 기술 | 설명 |
|------|------|
| 블록체인 DID | 분산신원인증으로 위변조 불가 |
| 생체인증 | 지문/얼굴 인식 필수 |
| 암호화 저장 | 신분 정보 암호화 보관 |
| 선택적 정보 공개 | 필요한 정보만 선택 제공 가능 |

### 분실 시 대처 방법

| 상황 | 조치 방법 |
|------|----------|
| 스마트폰 분실 | 정부24 또는 **1382** 전화로 즉시 정지 |
| 앱 삭제 | 앱 재설치 후 IC 태그/QR로 재발급 |
| 스마트폰 교체 | IC 방식: 태그로 재발급 / QR 방식: 주민센터 재방문 |

> 실물 신분증 분실보다 **빠르고 안전하게** 정지/재발급이 가능합니다.

## 7. 자주 묻는 질문 (FAQ)

### Q1. 발급 비용이 있나요?

**모바일 신분증 발급은 무료**입니다. 다만, IC 주민등록증을 새로 발급받을 경우 5,000~10,000원의 비용이 발생합니다.

### Q2. 스마트폰을 바꾸면 어떻게 하나요?

| 발급 방식 | 재발급 방법 |
|----------|------------|
| IC 태그 방식 | IC 신분증을 새 폰에 태그 (비대면) |
| QR 코드 방식 | 주민센터 재방문 필요 |

### Q3. 운전면허가 없어도 발급받을 수 있나요?

**네.** 모바일 주민등록증은 만 17세 이상 대한민국 국민이라면 누구나 발급받을 수 있습니다.

### Q4. 해외에서도 사용할 수 있나요?

**아니요.** 현재 모바일 신분증은 **국내 전용**입니다. 해외에서는 여권이 필요합니다.

### Q5. 실물 신분증도 들고 다녀야 하나요?

법적으로는 **모바일 신분증만으로 충분**합니다. 다만, 인식기가 없는 일부 장소에서는 실물 신분증이 필요할 수 있습니다.

### Q6. 부모님도 발급받을 수 있나요?

**네.** 스마트폰만 있으면 연령과 관계없이 발급 가능합니다. 주민센터 방문 시 QR 방식으로 간편하게 발급받을 수 있습니다.

### Q7. 어떤 앱을 설치해야 하나요?

| 앱 이름 | 다운로드 |
|--------|---------|
| 대한민국 모바일 신분증 | [Android](https://play.google.com/store/apps/details?id=kr.go.mobileid) / [iOS](https://apps.apple.com/kr/app/id1602877052) |

또는 삼성월렛, KB스타뱅킹, 네이버, 카카오뱅크, 토스 등 민간 앱에서도 발급 가능합니다.

