# 아이폰17 스펙 총정리: 일반 vs 프로 vs 에어 어떤 모델 살까?

"아이폰17 시리즈 나왔는데, 뭘 사야 할지 모르겠어요."

2025년 9월 출시된 아이폰17 시리즈! 이번엔 라인업이 완전히 바뀌었어요. 기존 Plus 모델이 사라지고, **역대 가장 얇은 아이폰 에어**가 새로 등장했거든요.

오늘은 아이폰17, 아이폰17 프로, 아이폰 에어의 스펙을 완벽하게 비교해드릴게요.

---

## 아이폰17 시리즈 라인업

### 2025년 아이폰17 시리즈 구성

| 모델 | 화면 크기 | 시작가 |
|------|----------|--------|
| 아이폰17 | 6.3인치 | $799 (약 116만원) |
| 아이폰 에어 | 6.5인치 | $999 (약 145만원) |
| 아이폰17 프로 | 6.3인치 | $1,099 (약 160만원) |
| 아이폰17 프로 맥스 | 6.9인치 | $1,199 (약 175만원) |

**핵심 포인트**: Plus 모델 대신 아이폰 에어가 등장! 역대 가장 얇은 5.6mm 두께로 화제가 됐어요.

---

## 아이폰17 (기본 모델)

### 주요 스펙

아이폰17은 이번에 **대폭 업그레이드**됐어요. 기존에 프로 모델에만 있던 기능들이 대거 내려왔습니다.

| 항목 | 아이폰17 |
|------|----------|
| 디스플레이 | 6.3인치 OLED |
| 주사율 | **120Hz ProMotion** (드디어!) |
| 칩셋 | A19 |
| RAM | 8GB |
| 후면 카메라 | 48MP 듀얼 (메인 + 초광각) |
| 전면 카메라 | **18MP Center Stage** |
| 배터리 | 더 길어진 배터리 수명 |
| 네트워킹 | Apple N1 칩 (Wi-Fi 7, Bluetooth 6) |

### 아이폰17 새로운 기능

- **ProMotion 120Hz**: 드디어 일반 모델에도 120Hz 적용!
- **더 큰 화면**: 6.1인치에서 6.3인치로 확대
- **Apple N1 칩**: Wi-Fi 7과 Bluetooth 6 지원하는 자체 설계 칩
- **향상된 내구성**: Ceramic Shield 2로 긁힘 방지 3배 향상
- **밝기 개선**: 야외에서 최대 3,000니트 밝기

**추천 대상**: 합리적인 가격에 프로급 디스플레이를 원하는 분!

---

## 아이폰 에어 (신규 모델)

### 역대 가장 얇은 아이폰

아이폰 에어는 이번 시리즈의 가장 큰 화제였어요. **5.6mm** 두께로 역대 가장 얇은 아이폰입니다!

| 항목 | 아이폰 에어 |
|------|------------|
| 디스플레이 | 6.5인치 OLED |
| 주사율 | 120Hz ProMotion |
| 칩셋 | **A19 Pro** |
| RAM | **12GB** |
| 후면 카메라 | 48MP 싱글 |
| 전면 카메라 | 18MP Center Stage |
| 프레임 | **티타늄** |
| 두께 | **5.6mm** (역대 최박) |
| 무게 | 165g (25% 가벼움) |

### 아이폰 에어의 특징

**장점**
- 5.6mm 초슬림 디자인
- 티타늄 프레임 (내구성 우수)
- A19 Pro 칩 탑재 (프로급 성능)
- 12GB RAM
- eSIM 전용 (전 세계 최초)

**단점**
- 싱글 카메라 (초광각, 망원 없음)
- 배터리 용량 작음 (27시간 영상 재생)
- mmWave 5G 미지원

**주의**: 아이폰 에어는 판매 부진으로 **2세대 모델이 2027년으로 연기**됐어요. 카메라가 하나뿐이라 선호도가 낮았다는 분석이 있습니다.

**추천 대상**: 초슬림 디자인을 원하고, 카메라는 기본만 있어도 되는 분!

---

## 아이폰17 프로 / 프로 맥스

### 역대급 성능 업그레이드

아이폰17 프로는 이번에 **설계부터 완전히 바뀌었어요**. 베이퍼 챔버 냉각 시스템이 아이폰 역사상 처음 도입됐습니다.

| 항목 | 아이폰17 프로 | 아이폰17 프로 맥스 |
|------|-------------|-----------------|
| 디스플레이 | 6.3인치 OLED | 6.9인치 OLED |
| 주사율 | 120Hz ProMotion | 120Hz ProMotion |
| 칩셋 | A19 Pro | A19 Pro |
| RAM | 12GB | 12GB |
| 후면 카메라 | 48MP 트리플 | 48MP 트리플 |
| 망원 줌 | **8배 광학 줌** | **8배 광학 줌** |
| 냉각 | **베이퍼 챔버** | **베이퍼 챔버** |
| 프레임 | 알루미늄 유니바디 | 알루미늄 유니바디 |

### 아이폰17 프로 핵심 업그레이드

**A19 Pro 칩**
- 3나노 공정 기반
- CPU 6코어, GPU 5코어 (+1코어)
- 전작 대비 CPU 15-20%, GPU 20% 성능 향상

**베이퍼 챔버 냉각**
- 아이폰 최초 베이퍼 챔버 도입
- 지속 성능 40% 향상
- 게임, 영상 편집 시 발열 감소

**카메라 시스템**
- 48MP 메인 + 48MP 초광각 + 48MP 망원
- **8배 광학 줌** (전작 5배에서 업그레이드)
- 24MP Center Stage 전면 카메라
- 듀얼 캡처 (전후면 동시 촬영)

**역대 최장 배터리**
- 아이폰 역사상 가장 긴 배터리 수명
- 25W MagSafe 무선 충전 지원

**추천 대상**: 최고 성능과 카메라를 원하는 분!

## 구매 시 체크포인트

### 1. 저장 용량 선택

| 모델 | 기본 용량 | 추천 용량 |
|------|----------|----------|
| 아이폰17 | 128GB | 256GB |
| 아이폰 에어 | 256GB | 256GB |
| 프로/프로맥스 | 256GB | 256GB~512GB |

**팁**: 4K 영상 많이 찍으면 512GB 이상 추천!

### 2. 트레이드인 활용하기

애플 트레이드인으로 기존 아이폰 보상받으면 상당한 할인 가능해요.

| 기존 모델 | 예상 보상금액 |
|----------|-------------|
| 아이폰15 프로 | 약 80-100만원 |
| 아이폰14 프로 | 약 50-70만원 |
| 아이폰13 | 약 25-40만원 |

### 3. 통신사 vs 자급제

- **통신사**: 공시지원금 + 카드 할인 조합
- **자급제**: 알뜰폰 사용 시 장기적으로 절약

## 자주 묻는 질문

### Q. 아이폰16 프로 쓰는데 바꿔야 할까요?

카메라 많이 쓰거나 게임 오래 하시면 베이퍼 챔버 냉각과 12GB RAM 체감됩니다. 그 외에는 급하게 바꿀 필요 없어요.

### Q. 아이폰 에어 왜 안 팔려요?

싱글 카메라가 가장 큰 이유예요. 요즘 폰으로 사진 많이 찍는데, 초광각이나 망원이 없으니 아쉬운 거죠. 2세대에서는 카메라 추가될 수도 있다는 루머가 있어요.

### Q. 프로 살까 프로맥스 살까요?

- 한 손 사용 → 프로 (6.3인치)
- 영상 많이 보고 배터리 중시 → 프로맥스 (6.9인치)

성능은 동일해요. 화면 크기와 배터리 차이입니다.

### Q. 아이폰18은 언제 나와요?

애플이 2026년 가을 아이폰18 출시를 **스킵**한다는 루머가 있어요. 다음 모델은 2027년 초에 나올 수 있습니다.
