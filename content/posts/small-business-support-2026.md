## 소상공인 정책자금

### 제도 개요

> **소상공인시장진흥공단에서 운영하는 저금리 정책자금 대출**

| 항목 | 내용 |
|------|------|
| 대출 한도 | 업체당 최대 **7억 원** |
| 금리 | 연 **2~4%** (시중금리 대비 저금리) |
| 상환 기간 | 5~8년 (거치 2년 포함) |
| 담보 | 신용보증 연계 (무담보 가능) |

### 자금 종류

| 자금 유형 | 대상 | 한도 |
|----------|------|------|
| **일반경영안정자금** | 경영 위기 소상공인 | 7억 원 |
| **성장촉진자금** | 성장 잠재력 있는 업체 | 5억 원 |
| **특별경영안정자금** | 재해·위기지역 업체 | 2억 원 |
| **청년고용특별자금** | 청년 고용 업체 | 5억 원 |

### 신청 자격

| 조건 | 내용 |
|------|------|
| 업종 | 소상공인 해당 업종 |
| 상시근로자 | 5인 미만 (제조업 10인 미만) |
| 사업 기간 | 6개월 이상 영업 |
| 신용 등급 | 신용등급 제한 없음 (일부 자금 제외) |

### 신청 방법

1. **소상공인마당** (www.sbiz.or.kr) 접속
2. 정책자금 신청 메뉴 클릭
3. 자격 자가진단 실시
4. 온라인 신청서 작성
5. 필요 서류 업로드
6. 상담 예약 및 심사
7. 승인 후 대출 실행

### 필요 서류

| 서류 | 비고 |
|------|------|
| 사업자등록증 | 필수 |
| 신분증 사본 | 대표자 |
| 재무제표 | 최근 2년분 |
| 부가세 과세표준증명 | 국세청 발급 |
| 사업장 임대차계약서 | 해당 시 |

## 자주 묻는 질문 (FAQ)

### Q1. 정책자금 신용등급 낮아도 되나요?

**일부 자금은 가능합니다.**

- 일반경영안정자금: 신용등급 6등급 이하도 신청 가능
- 신용보증재단 연계로 무담보 대출 가능
- 단, 금리 다소 높을 수 있음

### Q2. 1인 사업자도 고용지원금 받나요?

**고용이 없으면 해당되지 않습니다.**

- 일자리 안정자금: 근로자 고용 필수
- 1인 사업자는 정책자금, 세금 감면 활용

### Q3. 간이과세자인데 정책자금 가능한가요?

**네, 가능합니다.**

- 간이과세자도 소상공인 정책자금 신청 가능
- 매출 증빙 서류 대체 제출

### Q4. 프랜차이즈도 지원받을 수 있나요?

**일부 지원은 제한됩니다.**

- 정책자금: 가맹점도 신청 가능
- 일부 지원사업: 직영점 제외
- 개별 사업 확인 필요

### Q5. 온라인 쇼핑몰도 소상공인인가요?

**조건 충족 시 해당됩니다.**

- 상시근로자 5인 미만
- 통신판매업 신고
- 매출 기준 충족
