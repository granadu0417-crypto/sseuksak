## 핵심 요약

2026년 현재 탈모 인구는 약 **1,000만 명**에 달합니다. 탈모 치료는 조기에 시작할수록 효과가 좋으며, 크게 약물 치료와 모발이식으로 나뉩니다.

| 치료 방법 | 월 비용 | 효과 시작 | 핵심 특징 |
|----------|---------|----------|----------|
| 피나스테리드 | 1\~3만원 | 3\~6개월 | DHT 70% 억제, 부작용 적음 |
| 두타스테리드 | 2\~5만원 | 3\~6개월 | DHT 90% 억제, 효과 강력 |
| 미녹시딜 | 1\~3만원 | 2\~4개월 | 바르는 약, O자형에 효과적 |
| 모발이식 | 수백만원 (1회) | 6\~12개월 | 영구적, 자연스러운 결과 |

## 탈모의 원인과 종류

### 남성형 탈모 (안드로겐성 탈모)

전체 탈모의 약 95%를 차지합니다. 테스토스테론이 **5알파 환원효소**에 의해 **DHT(디하이드로테스토스테론)**로 전환되면서 모낭을 축소시킵니다.

| 특징 | 설명 |
|------|------|
| 패턴 | M자, O자(정수리), U자 형태로 진행 |
| 진행 | 점진적, 완전 탈락 가능 |
| 유전 | 모계/부계 모두 영향 |

### 여성형 탈모

호르몬 변화, 스트레스, 출산, 다이어트, 갑상선 질환 등이 원인입니다.

| 특징 | 설명 |
|------|------|
| 패턴 | 헤어라인 유지, 정수리·가르마 중심 |
| 진행 | 천천히, 완전 탈락은 드묾 |
| 시기 | 임신·출산 후, 중년 이후 증가 |

> 20대 여성 탈모 환자가 5년간 20% 증가했습니다. 스트레스, 다이어트, 수면 부족이 주요 원인입니다.

### 원형 탈모

자가면역 질환의 일종으로, 동전 크기의 원형으로 머리카락이 빠집니다. 건강보험 적용이 가능합니다.

## 약물 치료: 피나스테리드 vs 두타스테리드 vs 미녹시딜

### 피나스테리드 (프로페시아)

**2형 5알파 환원효소**만 억제하는 경구용 탈모 치료제입니다.

| 항목 | 내용 |
|------|------|
| 용량 | 1mg/일 |
| 효과 | DHT 약 70% 억제 |
| 비용 | 월 1\~3만원 |
| 효과 시작 | 3\~6개월 |
| 최대 효과 | 1\~2년 복용 시 |

**장점:**
- 부작용 발생률이 상대적으로 낮음
- 비용이 저렴한 편
- 오랜 임상 데이터 축적

### 두타스테리드 (아보다트)

**1형 + 2형 5알파 환원효소**를 모두 억제하는 더 강력한 약물입니다.

| 항목 | 내용 |
|------|------|
| 용량 | 0.5mg/일 |
| 효과 | DHT 90% 이상 억제 |
| 비용 | 월 2\~5만원 |
| 반감기 | 약 5주 (피나스테리드보다 김) |
| 체내 잔존 | 완전 소멸까지 약 6개월 |

**장점:**
- 피나스테리드보다 효과가 강력
- 두피 전반에 작용하는 1형 효소도 억제

### 미녹시딜

원래 고혈압 치료제로 개발되었으나, 발모 효과가 발견된 **바르는 외용제**입니다.

| 항목 | 내용 |
|------|------|
| 농도 | 남성 5%, 여성 2\~3% |
| 사용법 | 1일 2회 두피에 도포 |
| 비용 | 월 1\~3만원 |
| 효과 시작 | 2\~4개월 |

**미녹시딜의 3가지 효과:**
1. **혈류 개선**: 모낭에 영양 공급 증가
2. **성장 주기 연장**: 휴지기 모발을 성장기로 전환
3. **모발 밀도 개선**: 모발 굵기 증가

> M자형 탈모는 경구약(피나/두타), O자형(정수리) 탈모는 미녹시딜이 더 효과적입니다.

## 부작용 및 주의사항

### 경구약 공통 부작용

| 부작용 | 발생률 | 설명 |
|--------|--------|------|
| 성기능 장애 | 2\~15% | 성욕 감소, 발기부전 |
| 우울감 | 드묾 | 2025년 EMA 자살 사고 연관성 경고 |
| 여성형 유방 | 드묾 | 호르몬 불균형으로 발생 |

**복용 중단 시:**
- DHT는 2주 내 원래 수준으로 복원
- 3\~12개월 내 탈모 재발 가능
- 최소 1년 이상 꾸준히 복용해야 효과 유지

### 2세 계획 시 주의사항

| 약물 | 체내 완전 소멸 | 임신 계획 전 중단 시점 |
|------|---------------|----------------------|
| 피나스테리드 | 약 3개월 | 최소 3개월 전 |
| 두타스테리드 | 약 6개월 | 최소 6개월 전 |

> 가임기 여성은 피나스테리드, 두타스테리드 복용이 **금지**됩니다. 피부 접촉만으로도 태아에 영향을 줄 수 있습니다.

### 미녹시딜 부작용

| 부작용 | 설명 |
|--------|------|
| 초기 탈모 | 사용 초기 1\~2개월 일시적 탈모 증가 (정상) |
| 두피 자극 | 가려움, 건조함, 비듬 |
| 다모증 | 얼굴 등 원치 않는 부위에 털 증가 |
| 저혈압 | 드물게 두통, 어지러움 |

## 모발이식

약물 치료로 효과가 없거나, 이미 탈모가 많이 진행된 경우 모발이식을 고려합니다.

### 절개식 (FUT, Strip)

후두부 두피를 절개해 모낭을 채취하는 방식입니다.

| 항목 | 내용 |
|------|------|
| 장점 | 모낭 손상 적음, 대량 이식 가능, 경제적 |
| 단점 | 후두부 선형 흉터 |
| 수술 시간 | 3,000모 기준 약 4시간 |
| 회복 | 10일 후 실밥 제거 |

### 비절개식 (FUE)

펀치로 모낭을 하나씩 채취하는 방식입니다.

| 항목 | 내용 |
|------|------|
| 장점 | 선형 흉터 없음, 회복 빠름 |
| 단점 | 비용 더 높음, 채취량 제한 |
| 수술 시간 | 절개식보다 더 소요 |

### 모발이식 비용

| 모수 | 예상 비용 |
|------|----------|
| 1,000모 | 150\~300만원 |
| 2,000모 | 300\~500만원 |
| 3,000모 | 450\~700만원 |
| 4,000모 | 600\~900만원 |

> 비용은 병원, 의사 경력, 시술 방식에 따라 다릅니다. 여러 병원 상담을 권장합니다.

식약처에서 **탈모 증상 완화** 기능성 인정을 받은 제품이 있습니다.

| 성분 | 효과 |
|------|------|
| 맥주 효모 | 비타민 B군(비오틴), 단백질 공급 |
| 케토코나졸 | 항진균, 지루성 피부염 완화 |
| 징크피리치온 | 비듬, 두피 가려움 완화 |

**선택 기준:**
- 식약처 기능 보고 완료 제품
- 약산성 (pH 5.5 내외)
- 유해성분 배제 (파라벤, 실리콘 등)

## 정부 지원 및 비용 절감

### 건강보험 급여화 현황

2026년 현재, 남성형 탈모 치료제는 **비급여**입니다. 단, 원형 탈모 등 일부 질환은 급여 적용됩니다.

| 구분 | 급여 여부 |
|------|----------|
| 남성형/여성형 탈모 치료제 | X (비급여) |
| 원형 탈모 치료 | O (급여) |
| 탈모 진단 검사 | 일부 급여 |

> 정부는 탈모약 건강보험 급여화를 **검토 중**입니다. 연간 1,100억\~1,200억원의 재정 소요가 예상되어 신중한 논의가 진행 중입니다.

### 청년 건강 바우처 (검토 중)

| 항목 | 내용 |
|------|------|
| 대상 | 20\~30대 건강보험 가입자 (연간 병원 이용 4회 미만) |
| 지원액 | 전년도 납부 건보료의 약 10% (최대 12만원) |
| 사용처 | 병원·약국 (탈모 치료 비급여 사용 허용 검토) |
| 근거 | 제2차 국민건강보험 종합계획(2024\~2028) |

### 지자체 시범사업

일부 지자체에서 탈모 치료비 지원 사업을 운영하고 있습니다.

**성동구 사례:**

| 항목 | 내용 |
|------|------|
| 대상 | 만 39세 이하 성동구민 |
| 지원 | 경구용 탈모약 구매비 |
| 한도 | 연간 최대 20만원 |
| 방식 | 본인 부담 후 50% 환급 |

> 본인 거주지의 구청·시청 홈페이지에서 '탈모', '청년 건강' 키워드로 검색해보세요.

### 실손보험 활용

| 탈모 유형 | 보장 가능성 |
|----------|------------|
| 미용 목적 탈모 치료 | 보장 제외 경우 많음 |
| 병적 탈모 (원형탈모 등) | 진단서 있으면 보장 가능 |

아래 4가지 항목 중 2개 이상 해당되면 병원 상담을 권장합니다.

| 단계 | 체크 항목 |
|------|----------|
| 1 | 하루 100개 이상 머리카락이 빠진다 |
| 2 | 이마 헤어라인이 후퇴하고 있다 |
| 3 | 정수리 부분이 눈에 띄게 비어 보인다 |
| 4 | 가족 중 탈모가 있는 사람이 있다 |

## 자주 묻는 질문

### Q. 탈모약은 평생 먹어야 하나요?

탈모약을 중단하면 DHT가 2주 내 원래 수준으로 돌아갑니다. 효과를 유지하려면 **꾸준한 복용이 필요**합니다. 다만, 모발이식 후에는 약물 의존도가 줄어들 수 있습니다.

### Q. 피나스테리드와 두타스테리드 중 뭘 먼저 먹어야 하나요?

일반적으로 **피나스테리드를 먼저** 시도합니다. 부작용이 적고 비용도 저렴하기 때문입니다. 효과가 부족하면 두타스테리드로 전환을 고려합니다.

### Q. 미녹시딜과 경구약을 함께 사용해도 되나요?

네, **병용 사용이 권장**됩니다. 경구약은 DHT를 억제하고, 미녹시딜은 혈류를 개선해 시너지 효과를 낼 수 있습니다.

### Q. 모발이식 후에도 약을 먹어야 하나요?

이식된 모발 자체는 DHT에 강하지만, 기존 모발의 탈모 진행을 막으려면 약물 치료 병행이 권장됩니다.

### Q. 탈모 샴푸만으로 탈모를 막을 수 있나요?

탈모 샴푸는 **보조 수단**입니다. 두피 환경 개선에는 도움이 되지만, 근본적인 탈모 치료는 약물이나 시술이 필요합니다.

### Q. 20대인데 탈모가 시작됐어요. 어떻게 해야 하나요?

**빠른 병원 상담이 중요합니다.** 탈모는 진행성이므로 조기에 치료를 시작할수록 효과가 좋습니다. 피부과나 탈모 전문 병원을 방문하세요.

## 탈모 치료 단계별 가이드

### 1단계: 진단

| 할 일 | 설명 |
|-------|------|
| 병원 방문 | 피부과 또는 탈모 전문 병원 |
| 검사 | 두피 상태, 탈모 유형, 진행 정도 확인 |
| 원인 파악 | 유전, 호르몬, 스트레스 등 |

### 2단계: 약물 치료 시작

| 할 일 | 설명 |
|-------|------|
| 처방 | 피나스테리드 또는 두타스테리드 |
| 미녹시딜 | 병용 사용 고려 |
| 꾸준히 복용 | 최소 6개월\~1년 |

### 3단계: 경과 관찰

| 할 일 | 설명 |
|-------|------|
| 정기 검진 | 3\~6개월마다 |
| 효과 확인 | 사진 촬영으로 비교 |
| 부작용 체크 | 이상 시 의사 상담 |

### 4단계: 추가 치료 고려

| 조건 | 권장 치료 |
|------|----------|
| 약물 효과 부족 | 모발이식 상담 |
| 넓은 범위 탈모 | 모발이식 + 약물 병용 |
| 경제적 부담 | 지자체 지원 사업 확인 |
