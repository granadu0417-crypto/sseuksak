## 5. 전세대출 보증 종류

### 보증기관별 특징

| 보증기관 | 보증료 | 한도 | 특징 |
|---------|--------|------|------|
| **HUG (주택도시보증공사)** | 0.128%~0.154% | 최대 5억원 | 가장 보편적 |
| **SGI (서울보증보험)** | 0.183%~0.358% | 최대 5억원 | 심사 빠름 |
| **HF (한국주택금융공사)** | 0.05%~0.15% | 최대 5억원 | 정책대출 연계 |

### 보증 한도 계산

```
보증 한도 = 전세보증금 × 보증비율 - 선순위 채권

※ 보증비율: 수도권 80%, 지방 90%
```

**예시**: 전세보증금 4억원, 수도권
- 보증 한도: 4억 × 80% = 3.2억원

## 7. 전세대출 신청 절차

### Step by Step

```
1. 전세 계약 체결
   ↓ (계약금 지급 후)
2. 대출 상품 비교 및 선택
   ↓
3. 대출 신청 (온라인/방문)
   ↓
4. 서류 제출 및 심사 (3~7일)
   ↓
5. 보증서 발급 (1~3일)
   ↓
6. 대출 실행 (잔금일)
```

### 필수 서류

| 서류 | 용도 |
|------|------|
| 신분증 | 본인 확인 |
| 주민등록등본 | 세대 구성 확인 |
| 소득증빙서류 | 소득 확인 |
| 재직증명서 | 직장 확인 |
| 전세계약서 | 계약 내용 확인 |
| 등기부등본 | 권리관계 확인 |
| 확정일자 | 대항력 확보 |

### 타이밍 중요!

| 시점 | 해야 할 일 |
|------|-----------|
| 계약 직후 | 대출 상담 및 한도 조회 |
| 잔금 2주 전 | 정식 대출 신청 |
| 잔금 3일 전 | 보증서 발급 완료 확인 |
| 잔금일 | 대출 실행, 전입신고 |

## 8. 전세대출 금리 절약 팁

### 1. 정책대출 우선 검토

소득 요건 충족 시 정책대출이 **1~2% 이상** 저렴합니다.

### 2. 우대금리 조건 챙기기

| 우대 조건 | 적용 상품 | 우대폭 |
|----------|----------|--------|
| 급여이체 | 시중은행 | 0.1~0.3% |
| 적금 연계 | 시중은행 | 0.1~0.2% |
| 청년 | 정책대출 | 0.2~0.5% |
| 다자녀 | 정책대출 | 0.3~0.5% |

### 3. 보증기관 비교

HF(주택금융공사) 보증이 보증료가 가장 저렴합니다.

### 4. 대환대출 검토

기존 전세대출 금리가 **현재 금리보다 1% 이상 높다면** 대환을 고려하세요.

### 5. 금리 비교 사이트 활용

- **금융감독원 금융상품 한눈에**
- **주택도시기금 e든든**
- **네이버 대출 비교**

## 9. 전세대출 주의사항

### 전세사기 예방 체크리스트

| 체크 항목 | 확인 방법 |
|----------|----------|
| 등기부등본 확인 | 근저당, 가압류 여부 |
| 임대인 체납세금 | 국세, 지방세 열람 |
| 전입세대 확인 | 전입세대 열람 신청 |
| 시세 확인 | KB시세, 국토부 실거래가 |
| 집주인 본인 확인 | 신분증, 등기권리증 대조 |

### 갭투자 물건 주의

전세가율(전세가/매매가) **80% 이상**인 물건은 주의가 필요합니다.

### 확정일자 필수

전입신고와 확정일자는 **대출 실행 당일** 반드시 받으세요.

## 자주 묻는 질문

### Q1. 정책대출과 시중은행 대출, 동시 신청 가능한가요?

A. 동시 신청은 가능하지만, **둘 다 실행은 불가**합니다. 조건 비교 후 유리한 쪽으로 선택하세요.

### Q2. 전세대출 중도상환수수료가 있나요?

A. 상품에 따라 다릅니다:
- **정책대출**: 없음
- **시중은행**: 0~1.5% (대출 3년 내)
- **인터넷은행**: 대부분 없음

### Q3. 1인 가구도 청년버팀목 가능한가요?

A. 네, 만 34세 이하 **무주택 단독세대주**이면 가능합니다.

### Q4. 전세보증금 5억원인데, 얼마까지 대출받을 수 있나요?

A. 수도권 기준:
- **정책대출**: 한도 초과 (3억원 이하만 가능)
- **시중은행**: 5억 × 80% = 최대 4억원

### Q5. 집주인이 세금을 체납하면 어떻게 되나요?

A. 국세, 지방세가 전세권보다 **우선변제** 되므로, 체납이 있으면 보증서 발급이 거절될 수 있습니다. 계약 전 반드시 확인하세요.

## 마무리

2026년 전세대출은 **정책대출 활용**이 핵심입니다. 청년이라면 청년버팀목, 신혼부부라면 신혼부부 전용을 우선 검토하세요.

**전세대출 핵심 체크리스트**:
1. ✅ 정책대출 자격 요건 확인
2. ✅ 여러 상품 금리 비교
3. ✅ 우대금리 조건 최대한 활용
4. ✅ 보증기관 비교 (HF가 저렴)
5. ✅ 등기부등본, 체납세금 확인
6. ✅ 전입신고 + 확정일자 당일 처리

신중한 비교와 꼼꼼한 서류 준비로 안전하게 전세대출을 받으시기 바랍니다.
