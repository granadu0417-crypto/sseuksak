## 1. ChatGPT 실무 활용법

### ChatGPT란?

OpenAI에서 만든 대화형 AI예요. 가장 많이 쓰이는 AI 도구죠!

### 가격 정책

| 플랜 | 가격 | 특징 |
|------|------|------|
| 무료 | 0원 | GPT-4o mini, 기본 기능 |
| Plus | 월 $20 | GPT-4o, 이미지 생성 |
| Team | 월 $25/인 | 팀 기능, 보안 강화 |

### 실무 활용 예시

#### 1. 이메일 작성

**프롬프트 예시**:
```
다음 상황에 맞는 비즈니스 이메일을 작성해줘.

상황: 프로젝트 일정 지연을 고객사에 알리고 양해 구하기
- 지연 기간: 1주일
- 원인: 내부 테스트 중 버그 발견
- 톤: 정중하지만 신뢰감 있게
- 길이: 10줄 이내
```

**결과 활용**: AI가 작성한 초안 → 상황에 맞게 수정 → 발송

#### 2. 회의록 정리

**프롬프트 예시**:
```
아래 회의 내용을 정리해줘.

[회의 내용 붙여넣기]

형식:
1. 핵심 논의 사항 (3-5개)
2. 결정된 사항
3. 액션 아이템 (담당자, 기한 포함)
4. 다음 회의 안건
```

#### 3. 보고서 초안 작성

**프롬프트 예시**:
```
월간 마케팅 보고서 초안을 작성해줘.

데이터:
- 웹사이트 방문자: 50,000명 (전월 대비 +20%)
- 신규 가입자: 3,000명
- 광고 비용: 500만 원
- 매출: 5,000만 원

포함할 내용:
1. 요약 (Executive Summary)
2. 주요 성과
3. 개선점
4. 다음 달 계획
```

### ChatGPT 꿀팁

- 역할 부여하기: "너는 10년차 마케터야"
- 구체적으로 요청하기: "3가지로 정리해줘"
- 예시 보여주기: "이런 형식으로 작성해줘: [예시]"
- 피드백 주기: "더 간결하게 / 더 자세히"

## 2. Claude 실무 활용법

### Claude란?

Anthropic에서 만든 AI예요. **긴 문서 처리**에 특히 강해요!

### ChatGPT vs Claude

| 항목 | ChatGPT | Claude |
|------|---------|--------|
| 문서 길이 | 보통 | 매우 김 (20만 토큰) |
| 코딩 | 강함 | 강함 |
| 글쓰기 | 좋음 | 매우 좋음 |
| 파일 분석 | 가능 | 가능 (PDF 강점) |
| 특징 | 범용적 | 문서 특화 |

### 실무 활용 예시

#### 1. 긴 문서 요약

**프롬프트 예시**:
```
이 PDF 문서를 분석해서 다음을 정리해줘:

1. 핵심 내용 요약 (5줄)
2. 주요 데이터/수치
3. 실행 가능한 인사이트 3가지
```

> Claude는 100페이지가 넘는 PDF도 한 번에 분석 가능!

#### 2. 계약서/법률 문서 검토

**프롬프트 예시**:
```
이 계약서를 검토하고 다음을 알려줘:

1. 우리에게 불리한 조항
2. 협상이 필요한 부분
3. 빠진 중요 조항
4. 주의해야 할 점

[계약서 내용 붙여넣기 또는 파일 첨부]
```

#### 3. 연구 자료 분석

**프롬프트 예시**:
```
이 연구 보고서 3개를 비교 분석해줘.

분석 항목:
1. 공통된 결론
2. 상충되는 내용
3. 각 연구의 한계점
4. 종합 인사이트
```

### Claude 꿀팁

- 여러 파일 동시 분석 가능
- "Artifacts" 기능으로 코드/문서 별도 출력
- 긴 대화도 맥락 잘 유지
- 한국어 글쓰기 품질 좋음

## 3. 노션 AI 실무 활용법

### 노션 AI란?

노션(Notion) 안에 내장된 AI 기능이에요. 문서 작성 중에 바로 AI 도움을 받을 수 있어요!

### 가격

| 플랜 | 가격 | AI 사용량 |
|------|------|----------|
| 무료 | 0원 | 제한적 |
| Plus | 월 $10 | 무제한 |
| Business | 월 $15 | 무제한 |

### 실무 활용 예시

#### 1. 미팅 노트 정리

회의 중 막 적은 메모를 AI로 정리:

```
[스페이스바 누르고 "AI로 개선하기" 선택]
→ "회의록 형식으로 정리해줘"
```

#### 2. 브레인스토밍

빈 페이지에서:
```
[스페이스바] → "아이디어 브레인스토밍"
→ "2026년 마케팅 캠페인 아이디어 10개"
```

#### 3. 글 다듬기

작성한 글 선택 후:
```
→ "더 전문적으로"
→ "더 간결하게"
→ "영어로 번역"
```

### 노션 AI 단축키

| 기능 | 단축키 |
|------|--------|
| AI 호출 | Space (빈 줄에서) |
| 선택 영역 AI | Cmd/Ctrl + J |
| 요약하기 | 텍스트 선택 → 요약 |
| 번역하기 | 텍스트 선택 → 번역 |

## 4. Microsoft Copilot 실무 활용법

### Copilot이란?

마이크로소프트 365에 통합된 AI예요. **엑셀, 워드, PPT에서 바로** 사용 가능!

### 오피스별 활용법

#### Excel에서 Copilot

**할 수 있는 것들**:
- "이 데이터로 피벗 테이블 만들어줘"
- "매출 추이 그래프 그려줘"
- "이상치 데이터 찾아줘"
- "수식 설명해줘"

**프롬프트 예시**:
```
이 판매 데이터에서:
1. 월별 매출 합계 계산
2. 상위 10개 제품 추출
3. 전년 대비 성장률 계산
```

#### PowerPoint에서 Copilot

**할 수 있는 것들**:
- "이 문서로 PPT 만들어줘"
- "발표자 노트 작성해줘"
- "슬라이드 디자인 개선해줘"
- "요약 슬라이드 추가해줘"

**프롬프트 예시**:
```
이 기획안으로 10장짜리 발표 자료 만들어줘.
스타일: 심플하고 전문적
포함할 것: 목차, 현황, 전략, 예산, 일정
```

#### Word에서 Copilot

**할 수 있는 것들**:
- "이 보고서 요약해줘"
- "초안 작성해줘"
- "톤 변경해줘 (공식적/친근하게)"
- "길이 조절해줘"

## 5. Perplexity AI 실무 활용법

### Perplexity란?

**AI 검색 엔진**이에요. 구글처럼 검색하지만, AI가 답변을 정리해줘요!

### 구글 vs Perplexity

| 항목 | 구글 | Perplexity |
|------|------|------------|
| 결과 | 링크 목록 | 정리된 답변 |
| 출처 | 직접 확인 | 자동 표시 |
| 후속 질문 | 새로 검색 | 대화로 이어감 |
| 정확도 | 높음 | 높음 + 편리 |

### 실무 활용 예시

#### 1. 시장 조사

**프롬프트 예시**:
```
2026년 한국 이커머스 시장 현황 알려줘.
- 시장 규모
- 주요 플레이어
- 최신 트렌드
- 전망
```

> 결과에 **출처가 표시**되어 보고서에 인용 가능!

#### 2. 경쟁사 분석

**프롬프트 예시**:
```
[경쟁사 이름] 최근 1년 동향 분석해줘.
- 주요 뉴스
- 신제품/서비스
- 재무 현황
- 전략적 움직임
```

#### 3. 기술 트렌드 파악

**프롬프트 예시**:
```
2026년 AI 기술 트렌드 Top 5 정리해줘.
각 트렌드별로:
- 개요
- 적용 사례
- 우리 업무 적용 방안
```

### Perplexity Pro 기능 ($20/월)

- GPT-4, Claude 모델 선택 가능
- 파일 업로드 분석
- 더 긴 답변
- 무제한 Pro 검색

## AI 도구 활용 꿀팁 모음

### 1. 프롬프트 작성 공식

**좋은 프롬프트 = 역할 + 맥락 + 구체적 요청 + 형식**

나쁜 예: "마케팅 아이디어 알려줘"

좋은 예:
```
너는 10년차 마케팅 매니저야. [역할]
우리 회사는 20대 타겟 화장품 브랜드인데 [맥락]
SNS 마케팅 캠페인 아이디어 5개를 [구체적 요청]
각각 제목, 개요, 예상 효과로 정리해줘 [형식]
```

### 2. 반복 작업 템플릿 만들기

자주 쓰는 프롬프트는 저장해두세요!

**예시 - 회의록 템플릿**:
```
아래 회의 내용을 다음 형식으로 정리해줘:

## 회의 정보
- 일시:
- 참석자:
- 안건:

## 논의 내용
(핵심 위주로)

## 결정 사항


## 액션 아이템
| 담당자 | 할 일 | 기한 |
|--------|-------|------|

## 다음 회의 안건


[회의 내용]
```

### 3. AI 결과물 검증하기

AI 답변을 100% 믿지 마세요!

- 수치/통계: 반드시 출처 확인
- 최신 정보: 날짜 확인 (학습 데이터 기준)
- 전문 분야: 전문가 검토 필요
- 중요 문서: 여러 AI로 교차 검증

### 4. AI와 대화하듯 사용하기

한 번에 완벽한 결과를 기대하지 마세요!

1차: 초안 요청
→ "괜찮은데, 2번 부분 더 자세히"
→ "톤이 너무 딱딱해, 친근하게 바꿔"
→ "마지막에 CTA 추가해줘"
→ 최종 결과물!

- AI는 도구일 뿐
