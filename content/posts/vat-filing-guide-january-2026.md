## 소상공인 납부기한 2개월 연장

### 직권연장 대상자 (약 124만명)

국세청은 경기회복 지연으로 어려움을 겪는 소상공인을 위해 **납부기한을 신청 없이 자동 연장**합니다.

#### 연장 대상 조건 (모두 충족 시)

| 조건 | 내용 |
|------|------|
| **매출액** | 2024년 연간 매출액 10억원 이하 |
| **업종** | 제조, 건설, 도매, 소매, 음식, 숙박, 운수, 서비스업 (8개 업종) |
| **매출 감소** | 2025년 1기 매출액이 전년 동기 대비 30% 이상 감소 |

#### 간이과세자 전체 연장

| 대상 | 조건 | 연장 기한 |
|------|------|----------|
| 간이과세자 전체 | 매출 감소 여부 무관 | 3월 26일(목) |
| **제외** | 부동산임대업, 전문직 사업자 | 연장 제외 |

### 직권연장 대상 확인 방법

| 방법 | 경로 |
|------|------|
| **모바일** | 개별 안내문 발송 예정 |
| **홈택스** | 나의홈택스 메뉴에서 확인 |

### 추가 연장 신청 (직권연장 대상 외)

직권연장 대상이 아니더라도 경영상 어려움이 있다면 **최대 9개월**까지 납부기한 연장을 신청할 수 있습니다.

**신청 경로**:
- **홈택스**: 증명·등록·신청 → 세금관련 신청·신고 공통분야 → 신고분 납부기한 연장신청
- **손택스**: 전체메뉴 → 세금관련 신청·신고 공통분야 → 신고분 납부기한 연장신청
- **서면**: 납부기한등 연장 신청서를 세무서에 제출

## 부가세 신고 방법

### 전자신고 (권장)

| 방법 | 대상 | 이용시간 |
|------|------|----------|
| **홈택스 (PC)** | 모든 사업자 | 매일 06:00~다음날 01:00 |
| **손택스 (모바일)** | 모든 사업자 | 매일 06:00~다음날 01:00 |
| **ARS (1544-9944)** | 무실적 사업자만 | 24시간 |

> **마감일 주의**: 1월 12일(월), 1월 26일(월)은 06:00~24:00까지만 운영

### 홈택스 신고 경로

```
홈택스 접속 → 세금신고 → 부가가치세 신고 → 정기신고
```

### 세금비서 서비스 대상

다음 조건에 해당하면 **세금비서 서비스**로 더 쉽게 신고할 수 있습니다:

| 대상 | 조건 |
|------|------|
| 일반과세자 | 5종 서식으로 신고 완료하는 경우 |
| 부동산임대업자 | 부동산임대공급가액명세서 + 5종 서식 |
| 간이과세자 | 1개 업종 영위 사업자 |

**5종 서식**: 확정신고서, 매출·매입세금계산서 합계표, 신용카드 매출전표 발행금액 집계표·수령명세서

| | 신용카드 매출 | 1월 14일 |
| | 수출실적 내역 | 1월 11일 |
| **매입** | 현금영수증 매입 | 1월 1일 |
| | 사업용 신용카드 매입 | 1월 13일 |
| | 전자세금계산서 매입 | 1월 14일 |

2. 자동 입력된 금액과 실제 거래 내역 **반드시 대조**
3. 누락된 거래가 있다면 **수동 입력**

## 신고 전 필수 확인 - 신고도움서비스

홈택스에서 제공하는 맞춤형 신고 안내 자료를 반드시 확인하세요.

### 접근 경로

| 구분 | 경로 |
|------|------|
| **납세자** | 홈택스 → 세금신고 → 부가가치세신고 → 신고도움서비스 |
| **세무대리인** | 홈택스 → 세무대리·납세관리 → 세무대리공통조회 → 신고도움서비스 |

### 주요 맞춤형 도움자료 (125종, 123만명 대상)

| 유형 | 안내 내용 |
|------|----------|
| **매출** | 부동산임대업 면세전용·자가사용 자료, 계속 환급 신고자 안내 |
| **매입** | 개인적 사용 신용카드 수취자료 (유흥향락, 생활용품 등) |
| **공제** | 과·면세 겸업사업자 공통매입세액 안분 계산 안내 |

> **중요**: 신고도움자료를 반영하지 않고 불성실 신고 시 **추후 세금 추징** 및 **가산세** 부과 대상이 됩니다.

## 주의사항 - 불성실신고 추징 사례

국세청은 신고내용을 정밀 검증하여 불성실 신고자에게 **탈루세액을 추징**합니다. 2025년 한 해 동안 **2,700개 사업자**에서 **427억원**을 추징했습니다.

### 주요 추징 사례

| 유형 | 사례 | 결과 |
|------|------|------|
| **면세 관련** | 과세사업 목적 상가 취득 후 면세사업(학원)에 사용 | 매입세액 불공제 + 가산세 |
| **사업무관 비용** | 대표자 개인 주식거래 자문료 매입공제 | 매입세액 불공제 |
| **매출 누락** | 해외직구 성인용품 현금판매 미신고 | 탈루세액 추징 |

## 자주 묻는 질문

### Q1. 납부기한 연장 대상인지 어떻게 확인하나요?

A. 두 가지 방법으로 확인할 수 있습니다:
- **모바일**: 국세청에서 개별 안내문 발송
- **홈택스**: 나의홈택스 메뉴에서 직접 확인

### Q2. 신고는 했는데 세금을 못 내면 어떻게 되나요?

A. 납부기한 연장을 신청하세요:
- 직권연장 대상: 3월 26일까지 자동 연장
- 그 외: 신청 시 최대 9개월까지 연장 가능
- **미신청 시**: 납부지연 가산세 발생

### Q3. 매출이 없어도 신고해야 하나요?

A. 네, **무실적 신고**를 해야 합니다:
- ARS (1544-9944)로 간편 신고 가능
- 미신고 시 **무신고 가산세** 부과

### Q4. 간이과세자도 세금계산서를 발행할 수 있나요?

A. 제한적으로 가능합니다:
- 연 매출 4,800만원 이상: 세금계산서 발행 가능
- 연 매출 4,800만원 미만: 영수증만 발행 가능

### Q5. 환급은 언제 받나요?

A. 신고 유형에 따라 다릅니다:
- **조기환급**: 2월 4일(수) - 수출기업 등 세정지원 대상
- **일반환급**: 2월 13일(금) - 일반 사업자
