2026년 설날(음력 1월 1일)은 **2월 17일(화)**입니다. 설날 아침, 조상님께 새해 인사를 드리는 **차례**는 우리 민족의 소중한 전통입니다. 차례상 차리는 법이 복잡하게 느껴질 수 있지만, 기본 원칙만 알면 어렵지 않습니다.

## 1. 차례와 제사의 차이

| 구분 | 차례 | 제사 |
|------|------|------|
| 시기 | 설날, 추석 (명절) | 기일 (돌아가신 날) |
| 시간 | 아침 | 밤 (자정 무렵) |
| 대상 | 4대 조상까지 함께 | 해당 조상 1분 |
| 제물 | 떡국/송편 (계절 음식) | 밥과 국 |
| 절차 | 간소화된 형식 | 정식 절차 |

> 차례는 제사보다 간소한 형식으로, 명절에 온 가족이 함께 조상님께 감사드리는 의례입니다.

## 2. 차례상 기본 배치 원칙

차례상은 **신위(지방)를 기준으로 5열**로 배치합니다. 방향은 **신위를 바라보는 기준**이 아닌, **신위에서 바라보는 방향**입니다.

### 핵심 배치 원칙 4가지

| 원칙 | 한자 | 의미 |
|------|------|------|
| **홍동백서** | 紅東白西 | 붉은 과일은 동쪽(오른쪽), 흰 과일은 서쪽(왼쪽) |
| **어동육서** | 魚東肉西 | 생선은 동쪽, 육류는 서쪽 |
| **두동미서** | 頭東尾西 | 생선 머리는 동쪽, 꼬리는 서쪽 |
| **조율이시** | 棗栗梨枾 | 대추, 밤, 배, 감 순서 (왼쪽→오른쪽) |

### 동서남북 방향 이해하기

```
        북 (신위/지방)
          ↑
    서 ←     → 동
    (왼쪽)    (오른쪽)
          ↓
        남 (제주/절하는 곳)
```

## 3. 5열 배치도 상세 가이드

차례상은 신위에서 가까운 순서대로 1열~5열로 구성됩니다.

### 1열: 밥과 국 (신위와 가장 가까움)

| 위치 | 음식 | 설명 |
|------|------|------|
| 서쪽 (왼쪽) | 밥/떡국 | 설날: 떡국, 추석: 밥 |
| 가운데 | 술잔 | 잔반 (술잔과 받침) |
| 동쪽 (오른쪽) | 국/갱 | 쇠고기미역국 또는 맑은 장국 |

> 설날 차례에는 밥 대신 **떡국**을 올립니다.

### 2열: 적과 전 (구이류)

| 위치 | 음식 | 예시 |
|------|------|------|
| 서쪽 | 육적 | 쇠고기 산적, 돼지고기 적 |
| 가운데 | 소적 | 두부전, 채소전 |
| 동쪽 | 어적 | 생선전, 조기구이 |

### 3열: 탕 (국물 요리)

| 위치 | 음식 | 설명 |
|------|------|------|
| 서쪽 | 육탕 | 쇠고기탕 |
| 가운데 | 소탕 | 두부탕, 채소탕 |
| 동쪽 | 어탕 | 생선탕, 조개탕 |

> 탕은 1탕, 3탕, 5탕 등 홀수로 준비합니다. 간소화 시 1탕만 준비해도 됩니다.

### 4열: 포, 나물, 식혜 (반찬류)

| 위치 | 음식 | 예시 |
|------|------|------|
| 서쪽 | 포 | 북어포, 대구포, 오징어포 |
| 서쪽~가운데 | 나물 | 고사리, 도라지, 시금치 (3색 나물) |
| 동쪽 | 식혜/수정과 | 식혜 또는 수정과 |
| 동쪽 | 간장 | 조선간장 |

### 5열: 과일과 과자 (제주와 가장 가까움)

| 위치 | 음식 | 배치 원칙 |
|------|------|----------|
| 서쪽 → 동쪽 | 조율이시 | 대추 → 밤 → 배 → 감(곶감) |
| 그 외 | 기타 과일 | 사과(빨강), 귤, 바나나 등 |
| 양 끝 | 유과/약과 | 한과류 |

## 5. 차례상에 올리지 않는 음식

전통적으로 차례상에 **올리지 않는 음식**이 있습니다.

| 음식 | 이유 |
|------|------|
| **복숭아** | 귀신을 쫓는다고 여겨 조상을 멀리하는 의미 |
| **삼치, 갈치, 꽁치** | '치'자 돌림 생선은 천대받는 어종으로 여김 |
| **고춧가루/마늘** | 붉은 색과 강한 향이 귀신을 쫓는다고 여김 |
| **팥 (붉은 팥)** | 붉은 색이 조상을 쫓는다는 의미 |
| **비늘 없는 생선** | 장어, 미꾸라지 등은 올리지 않음 |

> 지역과 가문에 따라 다를 수 있으니, 집안 어른께 확인하세요.

## 7. 지방 쓰는 법

지방은 조상님을 모시는 신주(위패) 대용입니다.

### 지방 양식

```
┌─────────────────────────┐
│                         │
│  顯考學生府君神位       │  ← 아버지
│  (현고학생부군신위)      │
│                         │
│  顯妣孺人○○○氏神位    │  ← 어머니
│  (현비유인○○○씨신위)   │
│                         │
└─────────────────────────┘
```

### 지방 호칭

| 관계 | 남자 | 여자 |
|------|------|------|
| 아버지 | 顯考 (현고) | - |
| 어머니 | - | 顯妣 (현비) |
| 할아버지 | 顯祖考 (현조고) | - |
| 할머니 | - | 顯祖妣 (현조비) |
| 증조부 | 顯曾祖考 | - |
| 증조모 | - | 顯曾祖妣 |

> 직위가 있으면 '학생' 대신 직위를, 여성은 본관과 성씨를 넣습니다.

## 8. 지역별 차이

차례상 배치는 **지역과 가문에 따라 다릅니다**.

| 지역/가문 | 특징 |
|----------|------|
| **경상도** | 홍동백서 엄격, 3적 필수 |
| **전라도** | 다양한 해산물, 홍어 올리기도 함 |
| **충청도** | 간소한 편, 1탕 위주 |
| **서울/경기** | 절충형, 지역 음식 추가 |

> **가장 중요한 것**: 집안마다 전해 내려오는 방식을 따르는 것입니다. 어른께 여쭤보세요.

## 9. 현대적 간소화 차례상

바쁜 현대인을 위한 **간소화 차례상** 가이드입니다.

### 미니멀 차례상 (5가지)

| 필수 음식 | 설명 |
|----------|------|
| 떡국 | 설날의 상징 |
| 술 | 조상님께 올리는 정성 |
| 과일 3종 | 사과, 배, 감(또는 귤) |
| 나물 1~2종 | 시금치, 고사리 등 |
| 전 1~2종 | 동그랑땡, 생선전 |

### 대형마트 차례상 세트 활용

| 장점 | 단점 |
|------|------|
| 준비 시간 대폭 절약 | 가격이 비쌀 수 있음 |
| 배치 가이드 포함 | 집안 전통과 다를 수 있음 |
| 품질 균일 | 손맛이 부족할 수 있음 |

> 정성을 담아 직접 준비하되, 상황에 따라 간소화해도 조상님은 이해해 주실 것입니다.

## 11. 자주 묻는 질문 (FAQ)

### Q1. 차례상 방향이 헷갈려요

**A.** 신위(지방)를 북쪽으로 두고, 제주가 남쪽에서 절합니다. 동서는 신위 기준으로, 신위에서 봤을 때 오른쪽이 동쪽입니다.

### Q2. 과일 껍질을 깎아야 하나요?

**A.** 전통적으로 **배, 사과는 깎고**, 감, 대추, 밤은 그대로 올립니다. 하지만 요즘은 깎지 않고 올리는 집도 많습니다.

### Q3. 조율이시 순서가 헷갈려요

**A.** **조**(대추) → **율**(밤) → **이**(배) → **시**(감/곶감) 순서입니다. 왼쪽(서쪽)부터 배치합니다.

### Q4. 1인 가구도 차례를 지내야 하나요?

**A.** 형식보다 마음이 중요합니다. 간단히 떡국과 과일만 차려놓고 조상님께 인사드려도 됩니다.

### Q5. 종교가 다르면 어떻게 하나요?

**A.** 가족과 상의하여 결정하세요. 절 대신 묵념, 기도 등으로 대체하는 경우도 많습니다.
