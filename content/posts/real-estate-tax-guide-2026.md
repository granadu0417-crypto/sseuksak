# 2026년 부동산 세금 총정리

부동산을 취득하거나 보유, 양도할 때 다양한 세금이 발생합니다. 2026년에도 여러 세제 변화가 있는데요, 이 글에서는 **취득세, 양도소득세, 종합부동산세**를 중심으로 핵심 내용을 정리해 드립니다.

## 1. 취득세

### 주택 취득세율 (2026년)

| 주택 수 | 취득가액 | 세율 |
|---------|---------|------|
| **1주택** | 6억원 이하 | 1% |
| | 6억~9억원 | 2% |
| | 9억원 초과 | 3% |
| **2주택** | 조정대상지역 | 8% |
| | 비조정지역 | 1~3% |
| **3주택 이상** | 조정대상지역 | 12% |
| | 비조정지역 | 8% |
| **법인** | 전체 | 12% |

### 취득세 계산 공식

```
취득세 = 취득가액 × 세율

※ 실제 납부액 = 취득세 + 지방교육세(취득세의 10%) + 농어촌특별세
```

### 취득세 감면 혜택

| 감면 대상 | 감면율 | 조건 |
|----------|--------|------|
| 생애최초 주택 | 최대 200만원 | 부부합산 연소득 7,000만원 이하 |
| 신혼부부 | 50% 감면 | 혼인 7년 이내, 6억원 이하 |
| 다자녀 가구 | 50% 감면 | 18세 미만 자녀 3명 이상 |
| 장애인 | 면제 | 1~3급 장애인 |

> 💡 **Tip**: 생애최초 주택 취득 시 취득세 감면과 함께 **취득자금 증여 특례**(직계존속 5,000만원 비과세)도 함께 활용하세요.

|------|------|
| 보유 기간 | 2년 이상 |
| 거주 기간 | 2년 이상 (조정대상지역) |
| 양도가액 | 12억원 이하 |
| 세대 요건 | 양도일 현재 1세대 1주택 |

### 양도세 계산 예시

**조건**: 2020년 5억원 매수, 2026년 8억원 매도, 1세대 1주택, 6년 보유·거주

```
1. 양도차익: 8억 - 5억 = 3억원
2. 장특공제(48%): 3억 × 48% = 1.44억원
3. 양도소득금액: 3억 - 1.44억 = 1.56억원
4. 기본공제: 250만원
5. 과세표준: 1.56억 - 0.025억 = 1.535억원
6. 산출세액: 1.535억 × 35% - 1,544만원 = 약 3,829만원
7. 지방소득세: 약 383만원
→ 총 납부세액: 약 4,212만원
```

> 💡 12억원 이하 1주택이므로 **비과세**에 해당하여 실제 납부액은 0원입니다.

### 종부세 계산 예시

```
1. 과세표준: 15억 - 12억(공제) = 3억원
2. 세율 적용: 3억 × 0.5% = 150만원
3. 세부담 상한: 전년도 재산세+종부세 × 150%
4. 농어촌특별세: 종부세 × 20% = 30만원
→ 예상 종부세: 약 180만원
```

## 자주 묻는 질문

### Q1. 일시적 2주택, 비과세 받을 수 있나요?

A. 네, 다음 요건 충족 시 가능합니다:
- 종전 주택 2년 이상 보유
- 신규 주택 취득 후 3년 내 종전 주택 양도
- 종전 주택 양도가액 12억원 이하

### Q2. 부부 공동명의가 유리한가요?

A. 상황에 따라 다릅니다:
- **종부세**: 공동명의 시 공제액 2배 (유리)
- **양도세**: 각자 지분 계산, 장특공제 중복 (유리)
- **취득세**: 차이 없음

### Q3. 주택임대사업자 등록하면 세금 혜택이 있나요?

A. 2020년 이후 세제 혜택이 대폭 축소되었습니다. 현재는 종부세 합산 배제 정도의 혜택만 일부 유지됩니다.

### Q4. 상속받은 주택, 세금은 어떻게 되나요?

A. 상속세와 별개로:
- **취득세**: 상속 시 2.8% (농특세 포함 3.16%)
- **양도세**: 상속 당시 시가로 취득가액 산정
- **종부세**: 보유 주택에 합산

### Q5. 증여와 양도, 어떤 게 유리한가요?

A. 일반적으로:
- **시가 상승 예상**: 증여 유리 (미래 시세차익 절세)
- **시가 하락 예상**: 양도 유리 (현재 시점 과세)
- **자금 필요**: 양도 (현금 확보)
