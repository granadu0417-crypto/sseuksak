# 2026년 전기차 보조금 완벽 가이드: 차종별 지원금, 신청방법 총정리

"전기차 보조금, 올해는 얼마나 받을 수 있나요?"

2026년에도 전기차 구매 시 정부 보조금이 지급됩니다. 다만 예산 소진 시 조기 마감될 수 있으니 **빠른 신청**이 중요합니다!

## 2026년 전기차 보조금 개요

### 지원금 구성

| 구분 | 내용 |
|------|------|
| **국비 보조금** | 정부(환경부) 지원 - 전국 동일 |
| **지방비 보조금** | 지자체 추가 지원 - 지역별 상이 |
| **총 보조금** | 국비 + 지방비 |

### 2026년 보조금 규모

| 항목 | 내용 |
|------|------|
| 국비 보조금 | 차종별 **168만~570만 원** (성능 기반 차등 지급) |
| 국산 전기차 (현대/기아) | 약 **560~570만 원** |
| 수입 전기차 (테슬라 등) | 약 **168~170만 원** |
| 지방비 평균 | 150~400만 원 (지역별 상이) |
| 총 최대 | **약 970만 원** (국비 570만 + 지방비 400만) |

**2026년 주요 특징**:
- 국고보조금은 차량 성능(주행거리, 에너지효율 등)에 따라 차등 지급
- 국산 전기차가 수입차 대비 높은 보조금 적용
- 지방비는 지역별로 150~400만 원 추가 지원

## 신청 방법

### 신청 절차

1. **차량 선택 및 계약**
   - 대리점 방문 또는 온라인 예약
   - 보조금 신청 가능 여부 확인

2. **보조금 신청**
   - 대리점에서 대행 신청 (일반적)
   - 또는 본인 직접 신청

3. **심사 및 승인**
   - 지자체 심사 (1~2주)
   - 보조금 배정 확정

4. **차량 출고 및 등록**
   - 등록 시 보조금 차감 결제
   - 자기 부담금만 납부

### 필요 서류

| 서류 | 비고 |
|------|------|
| 신분증 사본 | 주민등록증 또는 운전면허증 |
| 주민등록등본 | 주소지 확인용 |
| 자동차매매계약서 | 대리점 발급 |
| 통장 사본 | 환급 시 필요 |
| 노후차 말소 증명 | 조기폐차 인센티브 신청 시 |

### 신청 채널

| 채널 | 방법 |
|------|------|
| **대리점 대행** | 가장 일반적, 대리점에서 처리 |
| **무공해차 통합누리집** | ev.or.kr - 직접 신청 |
| **지자체 홈페이지** | 각 시/군/구 환경부서 |

## 보조금 유의사항

### 의무 운행 기간

| 구분 | 기간 |
|------|------|

### 환수 기준

| 운행 기간 | 환수 비율 |
|----------|----------|
| 6개월 미만 | 100% 환수 |
| 6개월~1년 | 70% 환수 |
| 1년~2년 | 50% 환수 |
| 2년 이상 | 환수 없음 |

### 재지원 제한

- 이전 보조금 수령 후 **2년 이내** 재신청 불가
- 가구당 **1대** 원칙 (일부 지자체)

## 자주 묻는 질문 (FAQ)

### Q1. 보조금은 선착순인가요?

**네, 예산 소진 시 조기 마감됩니다.**

- 인기 지역은 상반기 조기 마감
- 연초 신청이 유리
- 지자체별 예산 확인 필요

### Q2. 중고 전기차도 보조금 받나요?

**신차만 해당됩니다.**

- 중고 전기차는 보조금 미지급
- 단, 세금 감면은 일부 적용

### Q3. 리스/렌트 차량도 보조금 받나요?

**네, 받을 수 있습니다.**

- 리스/렌트 회사가 보조금 신청
- 리스료/렌트료에서 보조금 차감

### Q4. 법인도 보조금 받나요?

**네, 법인도 가능합니다.**

- 법인 명의 구매 시 동일 지원
- 단, 일부 지자체에서 개인 우선 배정

### Q5. 보조금 신청 후 취소 가능한가요?

**출고 전이면 가능합니다.**

- 출고 후 취소 시 보조금 환수
- 차량 변경도 재신청 필요
